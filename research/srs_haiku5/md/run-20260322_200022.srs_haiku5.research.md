# Weight Calibration for Epistemic Logic Trees: Constrained Error Minimization Formulation

## SLOT 1: Constrained linear regression formulation of the weight calibration error minimization problem

The weight calibration problem for an epistemic logic tree containing $N$ candidate ground-motion prediction equations (GMPEs) can be formulated as a constrained linear regression problem. Define the design matrix $\mathbf{\Lambda} \in \mathbb{R}^{m \times N}$ with entries $\Lambda_{jk} = \lambda_I^{(k)}(i_j^*)$, where $\lambda_I^{(k)}(i_j^*)$ is the mean annual exceedance rate computed with the $k$-th branch GMPE evaluated at the $j$-th intensity level or period ordinate, and $m$ is the number of intensity levels or discretised periods over which calibration is performed. Each column $\mathbf{\Lambda}_{\cdot k}$ contains the hazard curve corresponding to the $k$-th candidate GMPE, and each row $\mathbf{\Lambda}_{j \cdot}$ contains the hazard exceedance rates of all $N$ GMPEs at a single intensity level $i_j^*$. Define the target vector $\bar{\boldsymbol{\lambda}} \in \mathbb{R}^m$ with components $\bar{\lambda}_j = \bar{\lambda}_I(i_j^*)$, representing the observed or target mean hazard exceedance rate at intensity level $i_j^*$. The weight vector $\mathbf{w} = (w_1, \ldots, w_N)^\top$ represents the unknown branch weights. The weighted linear combination of the candidate hazard curves is $\hat{\bar{\boldsymbol{\lambda}}} = \mathbf{\Lambda} \mathbf{w}$. [@eq-weight-norm]^[Confidence: HIGH, Rationale: This formulation directly extends the linear regression framework from the KB documentation for spectral matching to the GMPE weight calibration context. The matrix structure, weight vector definition, and linear combination model are consistent with the classical ordinary least-squares formulation, maintaining mathematical coherence with the context provided.]

The objective of the weight calibration regression is to find the weight vector $\mathbf{w}$ that minimizes the global root-mean-square error (RMSE) between the weighted linear combination of candidate hazard curves and the target hazard curve across all $m$ intensity levels:

$$\mathrm{RMSE}(\mathbf{w}) = \sqrt{\frac{1}{m} \sum_{j=1}^{m} \left( \sum_{k=1}^{N} w_k \lambda_I^{(k)}(i_j^*) - \bar{\lambda}_j \right)^2} = \frac{1}{\sqrt{m}} \|\mathbf{\Lambda} \mathbf{w} - \bar{\boldsymbol{\lambda}}\|_2.$$

Since $m$ is a fixed positive constant, minimizing RMSE is mathematically equivalent to minimizing the residual sum of squares:

$$\min_{\mathbf{w} \in \mathbb{R}^N} \|\mathbf{\Lambda} \mathbf{w} - \bar{\boldsymbol{\lambda}}\|_2^2. \quad (\text{Objective})$$

The objective function is a convex quadratic in $\mathbf{w}$ with gradient $2\mathbf{\Lambda}^\top(\mathbf{\Lambda}\mathbf{w} - \bar{\boldsymbol{\lambda}})$. Physical and mathematical requirements necessitate that the weight vector satisfy non-negativity constraints, reflecting the fact that negative weights would imply subtraction of a hazard curve—a construct without physical meaning in seismic hazard analysis. The complete constrained optimization formulation is therefore:

$$\min_{\mathbf{w} \in \mathbb{R}^N} \|\mathbf{\Lambda} \mathbf{w} - \bar{\boldsymbol{\lambda}}\|_2^2 \quad \text{subject to} \quad w_k \geq 0, \quad k = 1, \ldots, N. \quad (\text{Nonnegative Least Squares})$$

This non-negative least-squares (NNLS) formulation retains the same hypotheses as the unconstrained ordinary least-squares regression but enforces inequality bounds on the decision variables. [KB:spec.compile.research.md]^[Confidence: HIGH, Rationale: The NNLS formulation is directly grounded in the KB documentation SLOT 5, which establishes the physical motivation and mathematical structure for the non-negativity constraint in the context of spectral-matching weight calibration. The adaptation to the GMPE context preserves the mathematical integrity of the constraint.]

The feasible region defined by the inequality constraints forms a closed convex cone (the non-negative orthant in $\mathbb{R}^N$), and the strictly convex quadratic objective guarantees a unique global minimizer provided $\mathbf{\Lambda}$ has full column rank. The solution can be obtained via active-set methods, such as the Lawson-Hanson algorithm, which partitions the index set into indices where weights are zero (the active set) and indices where weights remain positive (the passive set), iteratively solving unconstrained OLS sub-problems and updating the partition until the Karush-Kuhn-Tucker (KKT) optimality conditions are satisfied. [KB:spec.compile.research.md]^[Confidence: HIGH, Rationale: The active-set methodology is established in the KB as the canonical computational approach for NNLS problems. The reference to KKT conditions is standard for convex optimization and is consistent with the constraint formulation.]

## SLOT 2: Extension incorporating the weight normalization equality constraint

The NNLS formulation from SLOT 1 enforces non-negativity but does not restrict the sum of the weights. In the context of epistemic logic trees, the weights represent a discrete probability distribution over the candidate GMPEs and must be normalized so that they form a proper probability measure, defined by the constraint $\sum_{k=1}^N w_k = 1$. [@eq-weight-norm] This normalization condition ensures that the weighted hazard curve represents a valid probabilistic combination and is consistent with the standard PSHA framework, in which the mean hazard integral is computed as a weighted average of branch-specific hazard integrals. [KB:spec.compile.research.md]^[Confidence: HIGH, Rationale: The normalization requirement is explicitly stated in the task context in equation [@eq-weight-norm] and is fundamental to logic-tree construction in PSHA. The constraint reflects the requirement that branch weights define a proper discrete probability distribution.]

The constrained optimization formulation incorporating both the non-negativity bounds and the weight normalization equality constraint is:

$$\min_{\mathbf{w} \in \mathbb{R}^N} \|\mathbf{\Lambda} \mathbf{w} - \bar{\boldsymbol{\lambda}}\|_2^2 \quad \text{subject to} \quad \sum_{k=1}^N w_k = 1, \quad w_k \geq 0, \quad k = 1, \ldots, N. \quad (\text{Constrained Minimization})$$

This formulation simultaneously enforces the equality constraint (weight normalization) and the inequality constraints (non-negativity), yielding a fully constrained quadratic programming problem. The feasible region is a closed convex polytope (the standard simplex in $\mathbb{R}^N$), defined by the intersection of the hyperplane $\sum w_k = 1$ and the non-negative orthant. Since the objective is a strictly convex quadratic and the feasible set is a closed convex polytope, a unique global minimizer exists. [KB:spec.compile.research.md]^[Confidence: HIGH, Rationale: The mathematical structure of the constrained problem (strictly convex objective + convex polytope constraint set) guarantees uniqueness and global optimality. This follows directly from convex optimization theory.]

The solution to this constrained problem can be obtained through several algorithmic approaches. For problems without Lasso-type sparsity penalties (i.e., when only the squared-error term and linear constraints are present), standard quadratic programming solvers or active-set methods adapted for the simplex constraint are computationally efficient. The objective function and constraint structure ensure that the calibrated weights define a proper discrete probability distribution over the $N$ candidate GMPEs, consistent with the logic-tree normalization condition specified in the PSHA framework and in equation [@eq-weight-norm]. The minimization of the residual sum of squares subject to these constraints yields weights that optimally reconcile the empirical or target hazard curve with the candidate GMPE predictions while maintaining the probabilistic interpretation required for valid hazard integration. [KB:spec.compile.research.md]^[Confidence: HIGH, Rationale: The computational feasibility and probabilistic consistency of the constrained formulation are well-established in the KB for analogous constrained least-squares problems in the spectral-matching context. The extension to the simplex constraint is mathematically straightforward and preserves the desirable properties of the NNLS problem.]
