## SLOT 1: Constrained linear regression formulation of the weight calibration error minimization problem

The weight calibration problem for epistemic ground-motion logic trees is formulated as a constrained linear regression problem in which the decision variables $w_k$ represent the branch weights assigned to each of the $N$ candidate ground-motion prediction equations. The objective is to determine non-negative weights that minimize the prediction error between the weighted combination of candidate GMPE predictions and a calibration target, such as observed ground motions or a reference prediction. [KB:spec.compile.research.md] This formulation extends classical ordinary least-squares regression by introducing explicit inequality constraints that enforce the physical requirement that all weights be non-negative. ^[Confidence: HIGH, Rationale: The formulation directly adapts the NNLS (non-negative least squares) problem presented in the KB (SLOT 5), which is well-established in optimization and regression literature. The physical motivation for non-negativity constraints is clearly articulated in the KB source.]

Define the design matrix $\mathbf{A} \in \mathbb{R}^{n \times N}$ with entries $A_{ij} = \hat{S}_{a,j}(T_i)$, where $\hat{S}_{a,j}(T_i)$ represents the ground-motion prediction from the $j$-th candidate GMPE evaluated at a specific ground-motion intensity measure (e.g., spectral acceleration) or aggregated measure at location $i$. Each column of $\mathbf{A}$ contains the predictions from a single candidate GMPE across all $n$ calibration constraints or observational data points, and each row contains the predictions of all $N$ candidate GMPEs at a single constraint or observation. [KB:spec.compile.research.md] The calibration target vector $\mathbf{b} \in \mathbb{R}^n$ contains the reference or observed values $b_i$ against which the GMPE predictions are to be matched. ^[Confidence: HIGH, Rationale: The design matrix formulation parallels the structure defined in KB SLOT 3, adapted from spectral ordinates to GMPE predictions. The parallel structure is conceptually sound for the epistemic weight calibration problem.]

The prediction error is measured as the residual between the weighted linear combination of candidate GMPE predictions and the calibration target. The objective function minimizes the sum of squared residuals, defining a convex quadratic optimization problem. Specifically, the objective function to be minimized is:

$$\min_{\mathbf{w} \in \mathbb{R}^N} \;\|\mathbf{A}\mathbf{w} - \mathbf{b}\|_2^2,$$

where $\mathbf{w} = (w_1, w_2, \ldots, w_N)^\top$ is the weight vector and $\|\cdot\|_2$ denotes the Euclidean norm. [KB:spec.compile.research.md] This objective is identical in structure to the unconstrained least-squares problem, but the constrained variant developed here explicitly restricts the feasible region. ^[Confidence: HIGH, Rationale: The formulation is the standard sum-of-squared-residuals objective from classical regression, directly cited in KB SLOT 3. The Euclidean norm formulation is mathematically equivalent to minimizing the residual sum of squares.]

The constrained linear regression formulation for weight calibration incorporates non-negativity inequality constraints on all weight components:

$$\min_{\mathbf{w} \in \mathbb{R}^N} \;\|\mathbf{A}\mathbf{w} - \mathbf{b}\|_2^2 \quad \text{subject to} \quad w_k \geq 0, \quad k = 1, 2, \ldots, N.$$

[KB:spec.compile.research.md] The feasible set is the non-negative orthant, a closed convex cone in $\mathbb{R}^N$. The objective function is a strictly convex quadratic in $\mathbf{w}$ with Hessian $2\mathbf{A}^\top\mathbf{A}$, which is positive semidefinite (or positive definite when $\mathbf{A}$ has full column rank). The combination of a strictly convex objective and a convex feasible set guarantees the existence of a unique global minimizer, provided that $\mathbf{A}$ has full column rank (i.e., $\text{rank}(\mathbf{A}) = N$, which requires $n \geq N$ and linear independence of the candidate GMPE prediction vectors). ^[Confidence: HIGH, Rationale: Convexity and uniqueness are fundamental properties of this problem class, rigorously established in KB SLOT 5 and standard optimization theory. The condition on matrix rank is explained in KB SLOT 3.]

The physical motivation for the non-negativity constraint is essential to the epistemic calibration problem. [KB:spec.compile.research.md] A negative weight $w_k < 0$ would imply subtracting a weighted contribution from the candidate GMPE $k$ in the final combined prediction, which would require an anti-GMPE with negated predictions—a construct with no physical foundation in seismic hazard assessment. No such anti-GMPE exists in any defensible collection of ground-motion models. Enforcing $w_k \geq 0$ for all $k$ ensures that the calibrated weights represent physically meaningful contributions from each branch GMPE to the ensemble prediction. Additionally, the non-negativity constraint often produces sparse solutions in which many weights are exactly zero, automatically performing simultaneous model selection and weight assignment. ^[Confidence: HIGH, Rationale: The physical argument and sparsity benefit are directly stated in KB SLOT 5, with explicit references to the meaninglessness of negative weights and the practical consequence of sparse solutions.]

The constrained least-squares problem defined above is the foundation upon which the fully normalized weight calibration problem is built in the subsequent slot. This formulation establishes the mathematical structure—objective function, decision variables, and inequality constraints—that ensures the calibrated weights minimize prediction error while remaining non-negative. The transition to enforcing weight normalization in SLOT 2 adds an additional equality constraint without changing the underlying convex quadratic objective or the non-negativity bounds. ^[Confidence: HIGH, Rationale: The formulation is self-contained and mathematically sound as a constrained linear regression problem. No external evidence is required to verify the structure; it is a direct specialization of well-known constrained optimization theory as applied to the epistemic weight context.]
