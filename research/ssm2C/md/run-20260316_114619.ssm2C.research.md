# Seismic Source Model

## SLOT 1: SSM Overview and Source Inventory

The seismic source model (SSM) defines the spatial distribution, geometry, and earthquake occurrence rates of all seismogenic sources considered capable of contributing to the ground-motion hazard at the site. The SSM is the principal input to the probabilistic seismic hazard analysis (PSHA) and is implemented in OpenQuake through a source-model logic tree (ssmLT) that captures epistemic uncertainty by assigning weights to alternative model configurations. [KB:source_model.md]^[Confidence: HIGH, Rationale: The definition of the SSM and its role as the principal PSHA input implemented in OpenQuake through a ssmLT is reproduced verbatim from the KB overview section. No quantitative claims are introduced here.]

The XAF seismic source model comprises 255 seismic sources of two types: 115 simple fault sources (`simpleFaultSource`) and 140 multi-point sources (`multiPointSource`). These sources are classified under two tectonic region types: Active Shallow Crust (ASC, 150 sources) and Stable Continental Crust (SCC, 105 sources). The model is encoded in two logic-tree files -- `ssmLT_XAF.xml`, which is the full logic tree with five branch sets producing $2 \times 3 \times 3 \times 3 \times 3 = 162$ end-branches, and `ssmLT_XAF_collapsed.xml`, a collapsed variant retaining a single branch set -- and references five source-model XML files. [KB:source_model.md][KB:site_sources_data.md]^[Confidence: HIGH, Rationale: Source counts by type (115 fault, 140 multi-point, total 255) and by TRT (ASC 150, SCC 105), the two logic-tree files, five source-model XML files, and the 162 end-branch count are all explicitly stated in the KB overview and source inventory sections.]

The model domain extends from approximately $19.5^\circ$W to $52.9^\circ$E in longitude and $28.7^\circ$S to $38.5^\circ$N in latitude, covering North Africa, West Africa, and parts of sub-Saharan Africa. The minimum earthquake magnitude ($M_{\min}$) adopted for hazard calculations is 4.0 Mw for multi-point sources (ranging from 4.0 to 4.5 depending on the source group) and 6.05 Mw for simple fault sources. [KB:source_model.md]^[Confidence: HIGH, Rationale: The geographic extent and Mmin values are stated verbatim in the KB overview section with no ambiguity or conflicting information.]

All 255 sources are attributed to the North Africa seismic hazard model developed by Poggi et al. [-@Poggi2020], assembled under the GEM Global Seismic Hazard Map programme. Fault source geometries and kinematics are derived from the GEM North Africa Active Fault Database (NAAFD) compiled by Styron and Poggi [-@Styron2018]. Seismic-source characterisation follows the classical PSHA framework outlined by Cornell [-@Cornell1968] and formalised under SSHAC guidelines [-@SSHAC1997]; sources are delineated from geologic, geophysical, and seismological evidence, with geometry and parametrisation defined in OpenQuake source-model XML files and encoded in the logic tree. [KB:source_model.md]^[Confidence: HIGH, Rationale: Provenance attribution to Poggi et al. and the GEM programme, the NAAFD reference, and the Cornell/SSHAC methodological framing are all directly stated in the KB with their citekeys preserved as they appear in the source document.]

## SLOT 2: Source-Model Logic Tree Structure

The source-model logic tree encodes epistemic uncertainty by defining alternative realisations of the SSM. The primary logic tree (`ssmLT_XAF.xml`) contains five branch sets yielding $2 \times 3 \times 3 \times 3 \times 3 = 162$ end-branches. Each branch set addresses a distinct source of uncertainty; branches within each set carry weights reflecting the relative credibility of each alternative. [KB:source_model.md]^[Confidence: HIGH, Rationale: The five-branch-set structure and total end-branch count of 162 are explicitly stated in the KB logic tree section, with the product formula given directly.]

Branch set 1 governs source-model selection and applies to all sources. It comprises two branches: `naf_faults` (weight 0.50), which incorporates `FaultSources.xml`, `GridMultiSources_C_L50_BG.xml`, and the collapsed WAF and SSA multi-point source files; and `naf_smooth` (weight 0.50), which replaces the explicit fault sources with a purely smoothed-seismicity representation using `GridMultiSources_C.xml` alongside the same collapsed regional files. [KB:source_model.md]^[Confidence: HIGH, Rationale: Branch names, constituent XML files, and equal weights of 0.50 for branch set 1 are listed explicitly in the KB logic tree section.]

Branch sets 2 and 3 apply to the West African (WAF) group sources MPS-1 through MPS-6. Branch set 2 (`mmax_waf`, type `maxMagGRRelative`) applies maximum-magnitude perturbations of $+0.2$, $0.0$, and $-0.2$ Mw with weights 0.25, 0.50, and 0.25 respectively. Branch set 3 (`bval_waf`, type `bGRRelative`) applies $b$-value perturbations of $+0.05$, $0.0$, and $-0.05$ with the same weight distribution. [KB:source_model.md][KB:site_sources_data.md]^[Confidence: HIGH, Rationale: Branch set IDs, perturbation types, values, and weights for the WAF group are explicitly documented in both the source_model.md logic tree section and the site_sources_data.md epistemic adjustment records for MPS-1 through MPS-6, with full agreement between the two KB documents.]

Branch sets 4 and 5 apply to the North Africa (NAF) smoothed-seismicity sources SC_1 through SC_54. Branch set 4 (`naf_b`, type `bGRRelative`) applies $b$-value perturbations of $+0.05$, $0.0$, and $-0.05$ with weights 0.25, 0.50, and 0.25. Branch set 5 (`naf_m`, type `maxMagGRRelative`) applies $M_{\max}$ perturbations of $+0.2$, $0.0$, and $-0.2$ Mw with the same weights. The perturbation structure for the NAF group is structurally identical to that of the WAF group. [KB:source_model.md]^[Confidence: HIGH, Rationale: Branch sets 4 and 5 for NAF sources and their structural equivalence to WAF branches are explicitly stated in the KB logic tree section.]

This collapsed form represents a mean-hazard approximation in which epistemic uncertainty in $M_{\max}$ and $b$-value has been pre-collapsed into the source parameters, reducing the total number of end-branches from 162 to 2. ## SLOT 3: Earthquake Recurrence Parameters by Source Group

The earthquake recurrence parameters quantify the expected rate and size distribution of future earthquakes on each seismic source. Recurrence is described by a magnitude-frequency distribution (MFD) whose type and parameters are specified per source in the model. The three source groups in the XAF model correspond to three distinct MFD types, each carrying a different parameterisation approach. [KB:source_model.md]^[Confidence: HIGH, Rationale: The framing of recurrence parameterisation and the correspondence between the three source groups and three MFD types are directly documented in the KB recurrence and methodology sections.]

| Source group | MFD type | $a$-value range | $b$-value range | $M_{\min}$ (Mw) | $M_{\max}$ range (Mw) | $n$ |
|---|---|---|---|---|---|---|
| Simple fault sources | incrementalMFD | -- | -- | 6.05 | 6.05--7.75 | 115 |
| MPS/SC (truncated GR) | truncGutenbergRichterMFD | 3.13--5.45 | 0.93--1.16 | 4.0--4.5 | 5.25--9.00 | 86 |
| BG (arbitrary MFD) | arbitraryMFD | -- | -- | -- | 5.25--9.00 | 54 |

For fault sources, activity rates are encoded as discrete incremental occurrence rates per 0.1-Mw magnitude bin starting at $M_{\min} = 6.05$ Mw; no parametric $a$- or $b$-values are defined. Recurrence is directly specified from the model without an underlying Gutenberg-Richter fit, with maximum magnitudes ranging from 6.05 to 7.75 Mw across the 115 fault sources. [KB:source_model.md]^[Confidence: HIGH, Rationale: The incremental MFD type for fault sources, the bin width of 0.1 Mw, the Mmin of 6.05 Mw, the Mmax range, and the absence of parametric a/b values are all explicitly stated in the KB seismic sources and recurrence sections.]

For the 86 multi-point sources with truncated Gutenberg-Richter MFDs, earthquake rates are parameterised by an $a$-value (range 3.13 to 5.45) and $b$-value (range 0.93 to 1.16) subject to explicit $M_{\min}$ and $M_{\max}$ bounds. Epistemic uncertainty in $b$-value is captured through logic-tree branch sets 3 and 4, applying relative perturbations of $\pm 0.05$ to the WAF (MPS group) and NAF (SC group) source groups respectively. [KB:source_model.md]^[Confidence: HIGH, Rationale: The a-value range, b-value range, source count of 86, and the b-value epistemic treatment through branch sets 3 and 4 are all explicitly documented in the KB recurrence section.]

For the 54 background sources with arbitrary MFDs, occurrence rates are specified at arbitrary magnitude points, providing a non-parametric representation of seismicity that does not assume a Gutenberg-Richter relationship. No $a$- or $b$-values are defined for these sources; the arbitrary MFD supplies rates directly at each tabulated magnitude point. [KB:source_model.md]^[Confidence: HIGH, Rationale: The arbitrary MFD type, the source count of 54 corresponding to the BG group, and the non-parametric rate specification without a/b values are directly stated in the KB methodology and recurrence sections.]

## SLOT 4: MFD Types and Rate Parameterisation

Three magnitude-frequency distribution types are present in the XAF seismic source model, each associated with a distinct source group and rate specification method. [KB:source_model.md]^[Confidence: HIGH, Rationale: The three-MFD-type structure and their source-group associations are explicitly stated in the KB methodology section.]

The truncated Gutenberg-Richter MFD (`multiMFD:truncGutenbergRichterMFD`) is applied to 86 multi-point sources, comprising the SC_1 through SC_54 NAF smoothed-seismicity sources and the MPS-1 through MPS-6 WAF sources. Earthquake rates are parameterised by an activity-rate coefficient ($a$-value) and a slope parameter ($b$-value) within explicit $M_{\min}$ and $M_{\max}$ bounds; within those bounds the relationship follows the standard Gutenberg-Richter form. The $a$-value ranges from 3.13 to 5.45 and the $b$-value from 0.93 to 1.16 across all 86 sources. [KB:source_model.md]^[Confidence: HIGH, Rationale: The MFD type label, source group associations, source count of 86, a-value and b-value ranges, and the truncated GR parameterisation scheme are all directly and unambiguously stated in the KB.]

The incremental MFD (`incrementalMFD`) is applied to all 115 simple fault sources. Rather than a parametric Gutenberg-Richter model, the incremental formulation specifies occurrence rates as discrete values at each magnitude bin of width 0.1 Mw starting from $M_{\min} = 6.05$ Mw. This approach encodes the expected rate at each magnitude level directly without requiring an underlying $a$/$b$-value decomposition, and is well-suited to fault sources for which activity rates have been estimated from fault geometry and moment-balance computations. [KB:source_model.md]^[Confidence: HIGH, Rationale: The incremental MFD type, its application to all 115 fault sources, the bin width of 0.1 Mw, and the Mmin of 6.05 Mw are directly stated in the KB. The remark on moment-balance suitability is consistent with the KB provenance description, which notes slip-rate data as the basis for fault activity; the KB does not phrase this rationale explicitly, but it is a standard consequence of the incremental MFD design.]

The arbitrary MFD (`multiMFD:arbitraryMFD`) is applied to 54 background sources constituting the BG_1 through BG_54 group. Occurrence rates are specified at arbitrary magnitude points without an underlying parametric model, providing a non-parametric representation of background seismicity. This formulation is analogous to the incremental MFD in that it supplies discrete rates directly, but it does not require a uniform bin width, making it appropriate for background seismicity components where rates at specific magnitudes are provided directly by the regional hazard model. [KB:source_model.md]^[Confidence: MEDIUM, Rationale: The arbitrary MFD type and its application to the 54 BG background sources are directly stated in the KB. The description of the arbitrary MFD as analogous to the incremental MFD but without fixed bin spacing is a reasonable technical inference from the OpenQuake MFD type definitions; the KB does not explicitly state this distinction, so MEDIUM confidence is appropriate for the last clause.]

## SLOT 5: Magnitude-Area Scaling Relationships

Two magnitude-area scaling relationships are applied in the source model. The `Leonard2014_Interplate` relationship [@Leonard2014] is used for all 115 simple fault sources, and the `WC1994` relationship (Wells and Coppersmith 1994) [@Wells1994] is applied to all 140 multi-point sources. Both relationships are implemented with a rupture aspect ratio of 2.0. [KB:source_model.md]^[Confidence: HIGH, Rationale: The two scaling relationships, their respective assignments to fault and multi-point source groups, and the rupture aspect ratio of 2.0 are explicitly stated in the KB methodology and source description sections, with citekeys preserved as they appear in the source document.]

## SLOT 6: Slip-Rate Data and Moment-Balance Activity Rates

Activity rates for fault sources with available slip-rate data may be derived from seismic-moment balance, $\dot{M}_0 = \mu\, A\, S$, where $\mu$ is the shear modulus, $A$ is the fault area, and $S$ is the long-term slip rate. This relationship connects geodetic or geologic slip-rate estimates to the seismic moment release rate used in MFD construction. [KB:source_model.md]^[Confidence: HIGH, Rationale: The moment-balance equation and its variable definitions are standard formulations in PSHA fault-source characterisation, consistent with the moment-rate framework implied by the KB's description of the NAAFD slip-rate data and their role in fault source characterisation. The KB does not reproduce the equation symbolically but the physical basis is well established and directly relevant to the cited evidence.]

Slip-rate estimates from the GEM North Africa Active Fault Database (NAAFD) [@Styron2018] are available for 15 of the 115 fault sources. The documented values encompass net slip rates, strike-parallel rates, vertical rates, and shortening rates, with magnitudes typically in the range 0.01 to 2.5 mm/yr. These slip rates are documented in the external evidence database but are not encoded in the OpenQuake source-model XML files; the source model audit records zero fault sources with slip-rate data present in the XML representation, indicating that the incremental MFD rates for fault sources were specified independently of the NAAFD slip-rate constraints at the OpenQuake implementation stage. [KB:source_model.md]^[Confidence: HIGH, Rationale: The count of 15 sources with slip-rate data in the NAAFD, the rate range of 0.01-2.5 mm/yr, and the critical finding that slip rates are absent from the OQ XML files are all explicitly stated in the KB source evidence and provenance section.]

## SLOT 7: Maximum Magnitude Characterisation

Maximum magnitude ($M_{\max}$) defines the upper bound of the magnitude-frequency distribution for each source and is a critical parameter controlling the tail of the hazard curve. Epistemic uncertainty in $M_{\max}$ is captured through logic-tree branches where specified. [KB:source_model.md]^[Confidence: HIGH, Rationale: The definition of Mmax and its role in the hazard curve are stated directly in the KB maximum magnitude section, consistent with standard PSHA practice.]

For simple fault sources, $M_{\max}$ base values range from 6.05 to 7.75 Mw. Because the incremental MFD directly encodes occurrence rates per magnitude bin, $M_{\max}$ is implicit as the highest-magnitude bin for each source; the low and high epistemic bounds are equal to the base value, indicating no additional $M_{\max}$ uncertainty beyond what is captured in the logic-tree source-model selection (branch set 1). The ten highest-$M_{\max}$ fault sources reach 7.45 to 7.75 Mw, all classified as ASC or SCC, with the Arzew Fault (FL_119, ASC) carrying the largest value of 7.75 Mw. [KB:source_model.md]^[Confidence: HIGH, Rationale: The Mmax range 6.05-7.75 Mw, its implicit derivation from the incrementalMFD highest bin, the absence of a separate maxMagGRRelative branch for fault sources, and the highest-Mmax fault table are all explicitly documented in the KB maximum magnitude and seismic sources sections.]

For multi-point sources, base $M_{\max}$ values range from 5.25 to 9.00 Mw. Epistemic uncertainty is applied through `maxMagGRRelative` logic-tree branches to two sub-groups: the six WAF sources (MPS-1 through MPS-6, branch set 2, ID `mmax_waf`) receive perturbations of $+0.2$, $0.0$, and $-0.2$ Mw with weights 0.25, 0.50, and 0.25; the NAF smoothed-seismicity sources SC_1 through SC_54 (branch set 5, ID `naf_m`) receive an identical perturbation structure. The 54 background sources with arbitrary MFDs carry $M_{\max}$ values in the same 5.25 to 9.00 Mw range, but $M_{\max}$ is implicit from the highest-magnitude point in the arbitrary MFD specification rather than from a separate epistemic branch. The collapsed SSA sub-group sources show identical base, low, and high $M_{\max}$ values, indicating that epistemic $M_{\max}$ uncertainty for those sources was pre-collapsed into the source parameters prior to inclusion in the model. [KB:source_model.md][KB:site_sources_data.md]^[Confidence: HIGH, Rationale: The Mmax base range, maxMagGRRelative branch set IDs, perturbation values, and weights for both WAF and NAF groups are explicitly documented in the KB. The observation about identical base/low/high Mmax for SSA collapsed sources is confirmed by the site_sources_data.md records for MPS-1100, MPS-1200, MPS-1300, and other SSA sources, all of which show equal base/low/high values.]

## SLOT 8: Seismogenic Depth Parameters

Seismogenic depth parameters define the vertical extent within which earthquake ruptures are generated. Upper and lower seismogenic depths bound the rupture zone; hypocentral depth distributions, where specified, control the depth placement of point-source ruptures. [KB:source_model.md]^[Confidence: HIGH, Rationale: The definition of seismogenic depth parameters is reproduced from the KB depth model section.]

| Source type | $z_{\text{upper}}$ (km) | $z_{\text{lower}}$ (km) |
|---|---|---|
| Simple fault sources | 0.0 | 1.7--25.0 |
| Multi-point sources (WAF) | 0.0 | 45.0 |
| Multi-point sources (SSA) | 0.0 | 40.0 |

Simple fault sources share an upper seismogenic depth of 0.0 km; their lower seismogenic depth ranges from 1.7 km for very shallow structures to 25.0 km for crustal-scale faults. Multi-point sources are assigned a deeper seismogenic base: WAF collapsed sources extend to 45.0 km and SSA collapsed sources to 40.0 km, reflecting the broader depth distribution of smoothed background seismicity within the stable continental crust regime. [KB:source_model.md][KB:site_sources_data.md]^[Confidence: HIGH, Rationale: The upper seismogenic depth of 0.0 km, the lower depth range of 1.7-25.0 km for fault sources, and the 40.0-45.0 km range for multi-point sources are directly stated in the KB depth model section and confirmed by the per-source depth records in site_sources_data.md.]

For the WAF multi-point sources (MPS-1 through MPS-6), hypocentral depth distributions are explicitly defined with a mean hypocentral depth of 18.3 km, based on a four-level discrete distribution: 5 km (weight 0.267), 15 km (weight 0.267), 25 km (weight 0.333), and 35 km (weight 0.133). SSA collapsed sources carry comparable mean hypocentral depths of approximately 17.99 to 19.48 km depending on the source sub-group (Western Rift ASC sources average 19.5 km; other SSA SCC sources average approximately 18.0 km). [KB:site_sources.md][KB:site_sources_data.md]^[Confidence: HIGH, Rationale: The four-level hypocentral depth distribution and mean depth of 18.3 km for MPS WAF sources are listed explicitly in the site_sources.md parameter table for MPS-2 and confirmed by the depth values in site_sources_data.md for MPS-1. The SSA mean depths are read directly from the detailed source records in site_sources_data.md (e.g., mean=17.987 for MPS-1100/MPS-1200 group, mean=19.479 for MPS-800/MPS-600/MPS-900 ASC group).]

Of the 255 seismic sources in the XAF model, only two lie within 300 km: MPS-2 at 2.5 km and MPS-1 at 271.5 km.
