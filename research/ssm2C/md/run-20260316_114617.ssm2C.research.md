# Seismic Source Model

## SLOT 1: SSM Overview and Source Inventory

The seismic source model (SSM) defines the spatial distribution, geometry, and earthquake occurrence rates of all seismogenic sources considered capable of contributing to ground-motion hazard at the site. The SSM is the principal input to the probabilistic seismic hazard analysis (PSHA) and is implemented in OpenQuake through a source-model logic tree (ssmLT) that captures epistemic uncertainty by assigning weights to alternative model configurations. [KB:source_model.md]^[Confidence: HIGH, Rationale: This opening definition is stated verbatim in source_model.md and is consistent with standard PSHA practice.]

The XAF seismic source model comprises 255 seismic sources of two types: 115 simple fault sources (`simpleFaultSource`) and 140 multi-point sources (`multiPointSource`). [KB:source_model.md][KB:site_sources_data.md] These sources are classified into two tectonic region types: Active Shallow Crust (ASC, 150 sources) and Stable Continental Crust (SCC, 105 sources). Breaking this down further, the 115 fault sources comprise 69 ASC and 46 SCC sources, while the 140 multi-point sources comprise 81 ASC and 59 SCC sources. [KB:source_model.md] The minimum earthquake magnitude ($M_{\min}$) adopted for hazard calculations is 4.0 Mw overall; multi-point sources carry $M_{\min}$ values in the range 4.0 to 4.5 Mw, whereas fault sources are defined from 6.05 Mw. [KB:source_model.md]^[Confidence: HIGH, Rationale: Source counts, TRT breakdown, and Mmin values are reported explicitly in source_model.md and corroborated by the source inventory table in site_sources_data.md.]

The model domain extends from approximately 19.5°W to 52.9°E in longitude and 28.7°S to 38.5°N in latitude, covering North Africa, West Africa, and parts of sub-Saharan Africa. The model is defined through two logic-tree files: `ssmLT_XAF.xml` (the full logic tree with five branch sets yielding 162 end-branches) and `ssmLT_XAF_collapsed.xml` (a collapsed variant retaining a single branch set with two branches). These logic-tree files reference five source-model XML files: `ssm_XAF/FaultSources.xml`, `ssm_XAF/GridMultiSources_C.xml`, `ssm_XAF/GridMultiSources_C_L50_BG.xml`, `ssm_XAF/WAF_GridMultiSources_Collapsed.xml`, and `ssm_XAF/SSA_GridMultiSources_Collapsed.xml`. [KB:source_model.md]^[Confidence: HIGH, Rationale: Domain extent, logic-tree file names, branch counts, and source-model XML filenames are explicitly enumerated in source_model.md.]

The adopted SSM is a composite assembled under the GEM Global Seismic Hazard Map programme. All 255 sources are attributed to the North Africa probabilistic seismic hazard model (NAF) developed by Poggi et al. [-@Poggi2020], with fault source geometries and kinematics derived from the GEM North Africa Active Fault Database (NAAFD) compiled by Styron and Poggi [-@Styron2018]. [KB:source_model.md]^[Confidence: HIGH, Rationale: Model attribution, programme affiliation, and provenance references are stated in source_model.md with citekeys preserved from the KB.]

Seismic-source characterisation follows the classical PSHA framework outlined by Cornell [-@Cornell1968] and formalised under SSHAC guidelines [-@SSHAC1997]. Sources are delineated from geologic, geophysical, and seismological evidence, with their geometry and parametrisation defined in OpenQuake source-model XML files and encoded in the logic tree. [KB:source_model.md]^[Confidence: HIGH, Rationale: The methodological framing citing Cornell 1968 and SSHAC 1997 is reproduced directly from source_model.md; both references are standard and authoritative for PSHA practice.]

## SLOT 2: Source-Model Logic Tree Structure

The source-model logic tree encodes epistemic uncertainty by defining alternative realisations of the SSM. Each branch set addresses a specific source of uncertainty, and the branches within each set are assigned weights reflecting the relative credibility of each alternative. The primary logic tree (`ssmLT_XAF.xml`) contains five branch sets yielding $2 \times 3 \times 3 \times 3 \times 3 = 162$ end-branches. The collapsed logic tree (`ssmLT_XAF_collapsed.xml`) retains only branch set 1, producing two branches and representing a mean-hazard approximation in which epistemic uncertainty in $M_{\max}$ and $b$-value has been pre-collapsed into the source parameters. [KB:source_model.md]^[Confidence: HIGH, Rationale: The number of branch sets, end-branches, and the description of the collapsed variant are stated explicitly in source_model.md.]

Branch set 1 addresses source-model selection and applies to all sources. It contains two branches of equal weight, encoding the principal structural uncertainty between a fault-inclusive realisation and a purely smoothed-seismicity realisation. ## SLOT 3: Earthquake Recurrence Parameters by Source Group

The earthquake recurrence parameters quantify the expected rate and size distribution of future earthquakes on each seismic source. Recurrence is described by a magnitude-frequency distribution (MFD) whose type and parameters are specified per source in the model. Three source groups are distinguished by their MFD type. [KB:source_model.md]^[Confidence: HIGH, Rationale: The three-group classification and the MFD types associated with each group are stated explicitly in source_model.md.]

Fault sources (115 sources) use an incremental MFD (`incrementalMFD`) with a bin width of 0.1 Mw starting at $M_{\min}$ = 6.05 Mw. Activity rates are encoded as discrete occurrence rates per magnitude bin; parametric $a$- and $b$-values are not defined for these sources. $M_{\max}$ ranges from 6.05 to 7.75 Mw across the fault population. [KB:source_model.md]^[Confidence: HIGH, Rationale: The incrementalMFD type, Mmin, absence of a/b values, and Mmax range for fault sources are all reported in source_model.md under the fault source and earthquake recurrence sections.]

The 86 multi-point sources carrying a truncated Gutenberg-Richter MFD (`multiMFD:truncGutenbergRichterMFD`) have $a$-values ranging from 3.13 to 5.45 and $b$-values ranging from 0.93 to 1.16, with $M_{\min}$ spanning 4.0 to 4.5 Mw. Epistemic uncertainty in $b$-value for this group is captured through logic-tree branch sets 3 and 4, which apply relative perturbations of $\pm 0.05$ to the WAF (MPS-1 through MPS-6) and NAF (SC_1 through SC_54) sources respectively. Base $M_{\max}$ values for these sources range from 5.25 to 9.00 Mw. [KB:source_model.md]^[Confidence: HIGH, Rationale: a-value range, b-value range, Mmin, and Mmax range for truncGR sources are stated explicitly in source_model.md; the b-value uncertainty structure is consistent with the logic-tree description.]

The 54 background multi-point sources use an arbitrary MFD (`multiMFD:arbitraryMFD`), in which occurrence rates are specified at discrete magnitude points without an underlying parametric model; no $a$- or $b$-values are defined. $M_{\max}$ values for these sources fall in the same 5.25-9.00 Mw range as the truncated GR multi-point sources. [KB:source_model.md]^[Confidence: HIGH, Rationale: The arbitraryMFD characterisation and the absence of a/b values for background sources are stated explicitly in source_model.md.]

## SLOT 4: MFD Types and Rate Parameterisation

Three MFD types are present in the XAF seismic source model, each serving a distinct modelling role. The selection of MFD type for a given source reflects both the available empirical data and the conceptual model of seismicity adopted for that source. [KB:source_model.md]^[Confidence: HIGH, Rationale: The three MFD types and their allocation across source groups are explicitly enumerated in source_model.md.]

The truncated Gutenberg-Richter MFD (`multiMFD:truncGutenbergRichterMFD`) is used by 86 multi-point sources, predominantly the SC_1 through SC_54 sources and the MPS-1 through MPS-6 sources. Earthquake rates are parameterised by an $a$-value (a measure of overall seismicity rate) and a $b$-value (the slope of the log-linear frequency-magnitude relationship), together with explicit $M_{\min}$ and $M_{\max}$ bounds. The annual rate of earthquakes with magnitude $M \geq m$ follows the truncated Gutenberg-Richter relation; the $a$-values in this model range from 3.13 to 5.45 and the $b$-values from 0.93 to 1.16. [KB:source_model.md]^[Confidence: HIGH, Rationale: The parameterisation of truncGR MFD and the numerical ranges for a and b are stated explicitly in source_model.md.]

The incremental MFD (`incrementalMFD`) is used by all 115 fault sources. Occurrence rates are specified as discrete values per 0.1 Mw magnitude bin starting at $M_{\min}$ = 6.05 Mw; $a$- and $b$-values are not defined for sources with this MFD type. This formulation directly encodes the expected annual rate at each magnitude level, allowing non-parametric shapes that may deviate from the Gutenberg-Richter relationship, as appropriate for individual fault rupture scenarios derived from paleoseismic or geodetic data. [KB:source_model.md]^[Confidence: HIGH, Rationale: The incrementalMFD type, its bin width, and the absence of a/b values are stated in source_model.md. The interpretation regarding non-parametric shapes is consistent with standard OpenQuake usage but is inferred from context rather than explicitly stated in the KB.]

The arbitrary MFD (`multiMFD:arbitraryMFD`) is used by 54 background multi-point sources (BG_1 through BG_54). Occurrence rates are specified at arbitrary, non-uniformly spaced magnitude points without an underlying parametric model, providing a non-parametric representation of distributed background seismicity that does not assume a Gutenberg-Richter relationship. [KB:source_model.md]^[Confidence: HIGH, Rationale: The arbitraryMFD type and its allocation to background sources are explicitly stated in source_model.md.]

## SLOT 5: Magnitude-Area Scaling Relationships

Two magnitude-area scaling relationships are applied in the source model, assigned by source type. All 115 simple fault sources use the `Leonard2014_Interplate` relationship [@Leonard2014] with a rupture aspect ratio of 2.0. All 140 multi-point sources use the `WC1994` relationship [@Wells1994] also with a rupture aspect ratio of 2.0. These relationships convert rupture area to moment magnitude and are used by OpenQuake to determine rupture dimensions during hazard calculation. [KB:source_model.md]^[Confidence: HIGH, Rationale: Both scaling relationships, their assignment to source types, and the rupture aspect ratio of 2.0 are explicitly stated in source_model.md, with citekeys Leonard2014 and Wells1994 preserved from the KB.]

## SLOT 6: Slip-Rate Data and Moment-Balance Activity Rates

Activity rates for fault sources with available slip-rate data are conceptually derivable from seismic-moment balance, $\dot{M}_0 = \mu\, A\, S$, where $\mu$ is the shear modulus, $A$ the fault area, and $S$ the long-term slip rate. This approach links the tectonic loading rate to expected earthquake recurrence. [KB:source_model.md]^[Confidence: HIGH, Rationale: The moment-balance equation and its variables are standard geophysical relationships; the conceptual framing is consistent with established PSHA methodology cited throughout source_model.md.]

Slip-rate estimates from the GEM North Africa Active Fault Database evidence base are documented for 15 of the 115 fault sources. These estimates encompass net slip rates, strike-parallel rates, vertical rates, and shortening rates, with values typically in the range 0.01 to 2.5 mm/yr. However, these slip-rate data are not encoded in the compiled OpenQuake source-model XML files; the model audit records `sources_with_slip_rate = 0`, confirming that the activity rates used in the hazard calculation are derived directly from the incremental MFD bins rather than from the moment-balance approach. [KB:source_model.md]^[Confidence: HIGH, Rationale: The count of 15 sources with slip-rate evidence, the slip-rate range, and the explicit note that sources_with_slip_rate = 0 in the XML are all stated in source_model.md under the slip-rate evidence section.]

## SLOT 7: Maximum Magnitude Characterisation

Maximum magnitude ($M_{\max}$) defines the upper bound of the magnitude-frequency distribution for each source and is a critical parameter controlling the tail of the hazard curve. Epistemic uncertainty in $M_{\max}$ is captured through logic-tree branches where specified. [KB:source_model.md]^[Confidence: HIGH, Rationale: The role of Mmax in the hazard curve and the logic-tree treatment of its uncertainty are stated in source_model.md.]

For fault sources, $M_{\max}$ ranges from 6.05 to 7.75 Mw (base values), derived implicitly from the highest magnitude bin in the incremental MFD for each source. No additional epistemic uncertainty in $M_{\max}$ is assigned to fault sources beyond the source-model selection uncertainty encoded in branch set 1; the low and high bounds are equal to the base value. The ten highest-$M_{\max}$ fault sources are concentrated in the ASC tectonic region, with the maximum value of 7.75 Mw assigned to the Arzew Fault (FL_119). [KB:source_model.md]^[Confidence: HIGH, Rationale: Fault source Mmax range, derivation method, and the absence of additional epistemic uncertainty are explicitly stated in source_model.md; the top-10 table values are reproduced directly.]

For multi-point sources, base $M_{\max}$ values span 5.25 to 9.00 Mw. Epistemic uncertainty is applied through `maxMagGRRelative` logic-tree branches in two branch sets. For WAF sources (MPS-1 through MPS-6), branch set 2 applies perturbations of +0.20, 0.00, and -0.20 Mw with weights 0.25, 0.50, and 0.25 respectively, yielding a range of approximately 5.05 to 9.20 Mw across branches. For NAF smoothed-seismicity sources (SC_1 through SC_54), branch set 5 applies an identical perturbation structure. The SSA collapsed sources (MPS-1100 through MPS-2000 series) carry no additional $M_{\max}$ uncertainty in the compiled model; their low and high values equal the base value. [KB:source_model.md][KB:site_sources_data.md]^[Confidence: HIGH, Rationale: Multi-point source Mmax base ranges, perturbation values, weights, and the absence of uncertainty for SSA collapsed sources are stated in source_model.md and corroborated in detail for individual sources in site_sources_data.md.]

## SLOT 8: Seismogenic Depth Parameters

Seismogenic depth parameters define the vertical extent within which earthquake ruptures are generated. Upper and lower seismogenic depths bound the rupture zone; hypocentral depth distributions, where specified, control the depth placement of point-source ruptures. [KB:source_model.md]^[Confidence: HIGH, Rationale: The conceptual definition of seismogenic depth parameters is stated in source_model.md and is consistent with standard OpenQuake source modelling practice.]

For simple fault sources, the upper seismogenic depth is 0.0 km for all 115 faults, indicating ruptures that may reach the surface. Lower seismogenic depth ranges from 1.7 km to 25.0 km, reflecting a wide range of fault geometries from very shallow structures to moderately deep crustal faults. Fault sources do not carry discrete hypocentral depth distributions; rupture geometry is instead determined by the fault trace, dip, and seismogenic depth interval combined with the magnitude-area scaling relationship. [KB:source_model.md]^[Confidence: HIGH, Rationale: Upper depth of 0.0 km for all faults and the lower depth range 1.7-25.0 km are explicitly stated in source_model.md. The absence of hypocentral distributions for fault sources is inferred from the KB, which describes them only for multi-point sources.]

For multi-point sources, the upper seismogenic depth is 0.0 km throughout, while the lower seismogenic depth ranges from 40.0 to 45.0 km, reflecting the broader depth distribution of smoothed background seismicity and crustal thickness variations across the model domain. Hypocentral depth distributions are defined for the WAF collapsed sources and provide discrete probability weights over depth values. For MPS-2 and MPS-1 (WAF group), the hypocentral depth distribution assigns weights of 0.267 at 5 km, 0.267 at 15 km, 0.333 at 25 km, and 0.133 at 35 km, yielding a mean hypocentral depth of approximately 18.3 km. For SSA collapsed sources (e.g., MPS-1100 through MPS-1500 series), lower seismogenic depth is 40.0 km and mean hypocentral depth ranges from approximately 18.0 to 19.5 km depending on the source group. [KB:source_model.md][KB:site_sources.md][KB:site_sources_data.md]^[Confidence: HIGH, Rationale: Lower depth ranges, hypocentral depth distribution values, and mean hypocentral depths are reported explicitly in source_model.md and confirmed in detail for individual sources in site_sources.md and site_sources_data.md.]

## SLOT 9: Local Sources and Site Tectonic Context

The Longonjo project site is located at coordinates 15.2485°E, 12.9080°S in central-western Angola. Of the 255 seismic sources in the XAF model, only two lie within 300 km of the site: MPS-2 at 2.5 km and MPS-1 at 271.5 km. Both belong to the Central Africa (WAF) smoothed-seismicity group within the `WAF_GridMultiSources_Collapsed.xml` file and are assigned to the Stable Continental Crust (SCC) tectonic region. The next closest source is MPS-1200 (Mweru-Katanga-Upemba) at 593 km, also SCC, followed by MPS-1100 (Luama Rift) at 875 km. The nearest Active Shallow Crust (ASC) source is MPS-800 (Western Rift-Tanganyika) at approximately 1,673 km. All North Africa fault sources lie beyond 4,000 km and are not expected to contribute to site hazard at any practical distance threshold. [KB:site_sources.md][KB:site_sources_data.md]^[Confidence: HIGH, Rationale: Site coordinates, source-to-site distances, TRT assignments, and distance rankings are all reported explicitly in site_sources.md and site_sources_data.md.]

The tectonic setting of the sources immediately surrounding the site is characterised as Stable Continental Crust, consistent with the geological position of central Angola on the Congo Craton, a Precambrian cratonic block distant from active plate boundary zones. The WAF smoothed-seismicity sources in this regime represent distributed intraplate seismicity rather than seismicity associated with active fault systems or rift structures. The nearest rift-related sources, classified as SCC (Mweru-Katanga-Upemba, Luama Rift), are situated within the southwestern arm of the East African Rift System at distances of 593-1,052 km. ASC regime sources, which carry higher $M_{\max}$ values (up to 7.9 Mw for the main rift branches), are all beyond 1,673 km. [KB:site_sources.md]^[Confidence: MEDIUM, Rationale: The SCC classification and distance to ASC sources are confirmed in site_sources.md; the geological interpretation attributing SCC classification to the Congo Craton setting is consistent with regional geophysics but is an inference not explicitly stated in the KB, introducing moderate uncertainty.]

From the characteristics of MPS-2, the geometrically dominant source at 2.5 km, the most relevant near-field events at the Longonjo site are expected to occur within the SCC tectonic regime at hypocentral depths of approximately 15-25 km (modal depth range from the hypocentral distribution), with moment magnitudes up to approximately $M_w$ 6.76 (base $M_{\max}$) or 6.96 Mw at the upper epistemic bound. The b-value of approximately 1.05 indicates a relatively steep frequency-magnitude slope typical of stable intraplate regions. Given the 2.5 km source-to-site distance, MPS-2 is expected to control the hazard across all return periods relevant to the SCC regime at this site, with its near-surface location implying low geometric attenuation for moderate-magnitude events. [KB:site_sources.md][KB:site_sources_data.md]^[Confidence: MEDIUM, Rationale: MPS-2 parameters (Mmax, depth, b-value, distance) are well constrained in the KB. The inference about hazard control and ground-motion implications is interpretive and not explicitly derived from PSHA deaggregation results, which are noted in site_sources.md as required for definitive identification of controlling sources.]
