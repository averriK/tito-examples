# Seismic Design Methods

## Response Spectrum Analysis (RSA)
RSA is a linear-elastic method that uses modal superposition. Peak modal responses are combined using SRSS or CQC rules. It is prescribed by ASCE 7-22 for regular structures.

## Nonlinear Time History Analysis (NLTHA)
NLTHA integrates equations of motion step-by-step using recorded or synthetic ground motions. Required by ASCE 7-22 for seismically isolated structures and structures with damping systems.

## Equivalent Lateral Force (ELF)
ELF distributes base shear as static lateral forces proportional to height. Limited to regular, low-rise structures per ASCE 7-22 Table 12.6-1.
