# Weight Calibration Under Sum-to-One Constraint: Formulation and Normalization Equivalence

## SLOT 1: Extend weight calibration formulation for sum-to-one constraint

The weight calibration problem for epistemic logic trees requires optimization of weights $w_k$ assigned to $K$ candidate ground-motion prediction equations (GMPEs) such that the weighted spectral combination approximates a target spectrum while satisfying three fundamental constraints: non-negativity, boundedness, and sum-to-one normalization. [KB:spec.compile.research.md]

The problem is formulated as a constrained least-squares minimization in log-spectral space. Let the transformed design matrix $\tilde{\mathbf{A}} \in \mathbb{R}^{n \times K}$ contain log-spectral ordinates of the candidate records, and let $\tilde{\mathbf{y}} \in \mathbb{R}^n$ denote the target vector in log-spectral coordinates. The weight calibration problem with all constraints is then expressed as:

$$\min_{\mathbf{w} \in \mathbb{R}^K} \left\|\tilde{\mathbf{A}}\mathbf{w} - \tilde{\mathbf{y}}\right\|_2^2 \quad \text{subject to} \quad w_{\min} \leq w_k \leq w_{\max} \text{ for all } k = 1, \dots, K, \quad \sum_{k=1}^{K} w_k = 1.$$

The objective function minimizes the squared $\ell_2$ norm of the residuals between the weighted linear combination of log-spectral ordinates and the target log-spectrum, measured across all $n$ period points in the discretization mesh. The equality constraint $\sum_{k=1}^{K} w_k = 1$ enforces that the weights form a convex combination, which is essential for the weights to represent a discrete probability distribution over candidate GMPEs in probabilistic seismic hazard analysis. [KB:spec.compile.research.md]

The feasible set defined by the constraints constitutes a convex polytope: the intersection of $2K$ inequality constraints (box constraints on each weight) and one linear equality constraint. The objective is a strictly convex quadratic function in $\mathbf{w}$, with Hessian matrix $2\tilde{\mathbf{A}}^\top\tilde{\mathbf{A}}$, which is positive semidefinite (positive definite when $\tilde{\mathbf{A}}$ has full column rank). The convexity of the objective and convexity of the feasible set guarantee that any local minimum is the unique global minimum. [KB:spec.compile.research.md]

The first-order optimality conditions are the Karush-Kuhn-Tucker (KKT) conditions. Let $\mu_k^-$ and $\mu_k^+$ denote the Lagrange multipliers for the inequality constraints $w_k \geq w_{\min}$ and $w_k \leq w_{\max}$, respectively, and let $\nu$ denote the Lagrange multiplier for the equality constraint $\sum_{k=1}^{K} w_k = 1$. The stationarity condition with respect to $w_k$ is:

$$2(\tilde{\mathbf{A}}^\top(\tilde{\mathbf{A}}\mathbf{w}^* - \tilde{\mathbf{y}}))_k + \mu_k^- - \mu_k^+ + \nu = 0, \quad k = 1, \dots, K,$$

where the subscript $k$ denotes the $k$-th component. Complementary slackness conditions enforce that $\mu_k^- \geq 0$ is nonzero only if $w_k^* = w_{\min}$ and $\mu_k^+ \geq 0$ is nonzero only if $w_k^* = w_{\max}$. Dual feasibility requires $\mu_k^-, \mu_k^+ \geq 0$ for all $k$, and primal feasibility requires that the solution satisfies all constraints. [KB:spec.compile.research.md]

This constrained formulation is a quadratic program (QP) with linear equality and inequality constraints. It generalizes the unconstrained OLS, the non-negativity-constrained (NNLS) formulation, and the bounded-weight formulations of prior work by adjoining an equality constraint that explicitly enforces the normalization requirement. When all weights are strictly interior to the bounds (i.e., $w_{\min} < w_k^* < w_{\max}$ for all $k$), the inequality constraints are inactive and the reduced problem is a constrained linear system determined by the equality constraint and the stationarity condition. [KB:spec.compile.research.md]

The problem can be solved using standard convex optimization algorithms: active-set methods (which maintain and update the sets of active inequality constraints), interior-point methods (which traverse the interior of the feasible region), or first-order methods such as augmented Lagrangian or alternating direction method of multipliers (ADMM). For moderate problem sizes (which are typical in GMPE logic tree applications, with $K$ often between 3 and 20 and $n$ between 50 and 100 ordinates), active-set algorithms such as those available in specialized QP solvers provide reliable and numerically stable solutions with fast convergence.

The complete problem statement with all constraints can be compactly expressed in the form of a standard constrained least-squares or quadratic program suitable for implementation in convex optimization libraries such as CVXR (in R) or CVXPy (in Python). The equality constraint transforms the problem from an unconstrained or inequality-only constrained problem into a constrained convex optimization problem with a uniquely defined global solution, provided the constraint qualification condition is satisfied (which it is, since the active constraints are linear and the equality constraint has full rank). ## SLOT 2: Validate normalization approach and justify mathematical treatment

Post-hoc normalization of an unconstrained or partially constrained weight solution is not mathematically equivalent to solving the constrained problem directly, and this approach requires careful examination of whether it preserves the properties of the original optimization solution. [KB:spec.compile.research.md]

Consider the unconstrained OLS solution $\hat{\mathbf{w}} = (\tilde{\mathbf{A}}^\top\tilde{\mathbf{A}})^{-1}\tilde{\mathbf{A}}^\top\tilde{\mathbf{y}}$ derived in SLOT 3 of the KB. This solution minimizes $\|\tilde{\mathbf{A}}\mathbf{w} - \tilde{\mathbf{y}}\|_2^2$ over all $\mathbf{w} \in \mathbb{R}^K$ without any constraints. If one were to post-hoc normalize this solution by dividing each component by the sum, yielding $\tilde{\mathbf{w}} = \hat{\mathbf{w}} / \sum_k \hat{w}_k$, the resulting normalized vector satisfies $\sum_k \tilde{w}_k = 1$ by construction. However, $\tilde{\mathbf{w}}$ does not minimize the original objective subject to the normalization constraint. [KB:spec.compile.research.md]

To see why, let $\mathbf{w}^* = \arg\min_{\mathbf{w}: \sum_k w_k = 1} \|\tilde{\mathbf{A}}\mathbf{w} - \tilde{\mathbf{y}}\|_2^2$ denote the true constrained solution. The KKT stationarity condition for the constrained problem is:

$$2\tilde{\mathbf{A}}^\top(\tilde{\mathbf{A}}\mathbf{w}^* - \tilde{\mathbf{y}}) + \nu \mathbf{1} = 0,$$

where $\nu$ is the Lagrange multiplier for the equality constraint and $\mathbf{1}$ is the vector of ones. This condition implies that the gradient of the objective at the constrained optimum is proportional to $\mathbf{1}$; that is, all components of the gradient are equal. In contrast, the unconstrained solution $\hat{\mathbf{w}}$ satisfies $2\tilde{\mathbf{A}}^\top(\tilde{\mathbf{A}}\hat{\mathbf{w}} - \tilde{\mathbf{y}}) = 0$, which means the gradient is exactly zero. Post-hoc normalization of $\hat{\mathbf{w}}$ does not yield a gradient proportional to $\mathbf{1}$, so the normalized weights $\tilde{\mathbf{w}}$ violate the KKT stationarity condition for the constrained problem. Therefore, $\tilde{\mathbf{w}} \neq \mathbf{w}^*$ in general. [KB:spec.compile.research.md]

However, there is a special case in which post-hoc normalization does preserve optimality, albeit in a modified sense. If the sum $\sum_k \hat{w}_k = 1$ already holds for the unconstrained solution, then $\tilde{\mathbf{w}} = \hat{\mathbf{w}}$ and the normalization is trivial; the unconstrained solution automatically satisfies the constraint. This occurs when the data matrix $\tilde{\mathbf{A}}$ and target $\tilde{\mathbf{y}}$ have specific symmetries or when the problem is formulated in centered coordinates. In general, however, without additional structure in the problem, the unconstrained solution does not automatically sum to one.

^[Confidence: HIGH, Rationale: The mathematical analysis correctly shows that post-hoc normalization of an unconstrained solution does not satisfy the KKT conditions of the constrained problem, and therefore yields a suboptimal solution. The KKT argument is sound and is directly derived from standard convex optimization theory as applied to the problem in the KB.]

A second scenario arises when one considers post-hoc normalization of a non-negatively constrained solution (NNLS). The NNLS solution $\hat{\mathbf{w}}_{\geq 0}$ minimizes $\|\tilde{\mathbf{A}}\mathbf{w} - \tilde{\mathbf{y}}\|_2^2$ subject to $w_k \geq 0$ for all $k$. If one normalizes this solution to obtain $\tilde{\mathbf{w}} = \hat{\mathbf{w}}_{\geq 0} / \sum_k \hat{w}_k^{\geq 0}$, again the normalized weights satisfy $\sum_k \tilde{w}_k = 1$ and $\tilde{w}_k \geq 0$, but they do not minimize the objective among all weights satisfying both constraints. The KKT stationarity condition for the NNLS-plus-normalization problem is:

$$2\tilde{\mathbf{A}}^\top(\tilde{\mathbf{A}}\mathbf{w}^* - \tilde{\mathbf{y}}) + \nu \mathbf{1} + \boldsymbol{\mu} = 0,$$

where $\nu$ is the multiplier for the equality constraint and $\boldsymbol{\mu}$ is the vector of multipliers for $w_k \geq 0$. Normalizing the NNLS solution does not satisfy this condition in general, so again the normalized weights are suboptimal. [KB:spec.compile.research.md]

The validity of post-hoc normalization hinges on a key mathematical distinction: normalization does not preserve optimality of the original unconstrained or partially constrained solution when viewed as a solution to the fully constrained problem. However, normalization does preserve the property that the resulting weights form a convex combination and are non-negative. If the goal is merely to ensure that weights are convex-combined non-negative values that approximate a target (without requiring optimality with respect to the weighted-error objective), then normalization is valid. But if the goal is to obtain the solution that minimizes prediction error subject to all constraints simultaneously, then one must solve the constrained problem directly using algorithms designed for constrained optimization.

^[Confidence: HIGH, Rationale: The analysis demonstrates that post-hoc normalization does not preserve KKT optimality conditions for the constrained problem. The mathematical treatment shows clearly when normalization is valid (as a convex-combination transformation) and when it is not (as an optimization-preserving transformation). This reasoning is grounded in standard convex optimization theory.]

The practical implication is that applications requiring optimal weight calibration subject to sum-to-one normalization, non-negativity, and bounding constraints must employ a constrained solver rather than relying on post-hoc normalization of an unconstrained or partially constrained solution. Standard QP solvers or convex optimization libraries provide the necessary tools to solve this problem exactly. The small computational overhead of solving the constrained problem directly is negligible compared to the potential loss in optimality and prediction accuracy resulting from post-hoc normalization of a suboptimal weight vector.

## Mathematical Summary

The weight calibration problem for epistemic logic trees with sum-to-one normalization is a strictly convex quadratic program with linear equality and inequality constraints. The problem admits a unique global solution that minimizes spectral prediction error while enforcing non-negativity, boundedness, and convex-combination normalization of the weights. Post-hoc normalization of unconstrained or partially constrained solutions is not equivalent to solving the constrained problem and does not preserve optimality; the constrained problem must be solved directly using dedicated algorithms. [KB:spec.compile.research.md]
