# Metal Properties

## Iron
- Atomic number: 26
- Melting point: 1538 C
- Density: 7.874 g/cm3

^[Confidence: HIGH, Rationale: All three values for iron are consistent with authoritative external sources. The atomic number (26) and melting point (1538 C) match the Royal Society of Chemistry periodic table entry exactly [@Ref001]. The stated density of 7.874 g/cm3 corresponds to the accepted standard; the RSC lists 7.87 g/cm3, the minor discrepancy reflects a difference in rounding precision rather than a factual error [@Ref001].]

## Copper
- Atomic number: 29
- Melting point: 1085 C
- Density: 8.96 g/cm3

^[Confidence: HIGH, Rationale: The atomic number of copper (29) and density (8.96 g/cm3) are confirmed as correct by the Royal Society of Chemistry periodic table [@Ref002]. The melting point stated as 1085 C is a rounded value of the standard 1084.62 C [@Ref002]; this rounding is a common convention and does not constitute a factual error.]

## Aluminum
- Atomic number: 13
- Melting point: 660 C
- Density: 2.70 g/cm3

^[Confidence: HIGH, Rationale: All three values for aluminum are confirmed by authoritative external sources. The atomic number (13), melting point (660 C, rounded from the standard 660.323 C), and density (2.70 g/cm3) are consistent with the Royal Society of Chemistry periodic table data [@Ref003]. The minor rounding of the melting point is a standard convention and does not represent a factual error.]
