# Seismic Source Model: Regional Architecture and Site Characterisation

## SLOT 1: SSM Overview and Source Census

The seismic source model (SSM) defines the spatial distribution, geometry, and earthquake occurrence rates of all seismogenic sources considered capable of contributing to ground-motion hazard at the site. The SSM is the principal input to the probabilistic seismic hazard analysis (PSHA) and is implemented in OpenQuake through a source-model logic tree (ssmLT) that captures epistemic uncertainty by assigning weights to alternative model configurations. The adopted SSM is based on the seismic hazard model for the Indian subcontinent developed by Nath and Thingbaijam [-@Nath2012], updated and translated into OpenQuake in collaboration with Natural Resources Canada, as documented in the GEM model report (version v2012.2.0) [-@GEM_IND]. [KB:source_model.md][KB:ind-report.pdf.md]^[Confidence: HIGH, Rationale: The model overview, provenance, and version are explicitly stated in source_model.md (section "Adopted Source Model") and confirmed by ind-report.pdf.md, which documents the same v2012.2.0 version, authorship (Ackerley, Thingbaijam, Nath), and OQ translation history. No contradictions between KB documents on these facts.]

The IND seismic source model comprises 443,197 seismic sources of two types: 108 area sources (`areaSource`) and 443,089 point sources (`pointSource`). These sources span four tectonic region types: Subduction Intraslab (SIS, 139,977 sources), Subduction Interface (SIF, 123,775 sources), Stable Continental Crust (SCC, 94,450 sources), and Active Shallow Crust (ASC, 84,995 sources). The minimum magnitude ($M_{\min}$) adopted for hazard calculations across all area sources is 4.5 Mw. [KB:source_model.md]^[Confidence: HIGH, Rationale: Source type and TRT-level counts are stated explicitly in source_model.md. The total count 443,197 = 108 + 443,089 is internally self-consistent. The $M_{\min}$ = 4.5 Mw figure is directly stated ("The minimum magnitude across all area sources is 4.5 Mw") and is confirmed by the Mmin field in the site-specific source data for zones z919 and z932.]

The model domain extends from approximately $60.0^\circ$E to $100.8^\circ$E in longitude and $2.0^\circ$N to $40.0^\circ$N in latitude, covering India, Bangladesh, Bhutan, Nepal, Pakistan, Myanmar, and surrounding regions of the Indian subcontinent. [KB:source_model.md]^[Confidence: HIGH, Rationale: Geographic bounds are explicitly stated in source_model.md and are consistent with the described tectonic coverage. The ind-report.pdf.md confirms coverage of India, Bangladesh, Bhutan, and Nepal.]

The model is defined through three logic-tree files: `ssmLT_IND.xml` (the full logic tree comprising three branch sets), `ssmLT_IND_collapsed.xml` (a collapsed variant), and `ssmLT_IND_garage_v1.xml` (an alternative full variant). The primary logic tree (`ssmLT_IND.xml`) references three source-model XML files and produces 27 end-branches from the Cartesian product of the three branch sets ($3 \times 3 \times 3 = 27$). [KB:source_model.md]^[Confidence: HIGH, Rationale: The three logic-tree filenames, the reference to three source-model XML files, and the 27 end-branch count are all explicitly stated in source_model.md. The arithmetic $3 \times 3 \times 3 = 27$ is consistent with the three branch sets each containing three branches, as documented in the Logic Tree Structure section.]

Seismic-source characterisation follows the classical PSHA framework outlined by Cornell [-@Cornell1968] and formalised under SSHAC guidelines [-@SSHAC1997]. Sources are delineated from geologic, geophysical, and seismological evidence, with geometry and parametrisation defined in OpenQuake source-model XML files and encoded in the logic tree. The implementation repository is publicly available at `nackerley/indian-subcontinent-psha` on GitHub [-@nackerley_repo]. [KB:source_model.md]^[Confidence: HIGH, Rationale: The Cornell (1968) and SSHAC (1997) framework citations are preserved verbatim from source_model.md, which explicitly invokes these methodological foundations in its "Source Model Methodology" section. The GitHub repository reference is stated in source_model.md and in ind-report.pdf.md, providing corroboration across two KB documents.]

## SLOT 2: Source-Model Logic Tree Structure

The source-model logic tree encodes epistemic uncertainty by defining alternative realisations of the SSM. Each branch set addresses a specific source of uncertainty, and the branches within each set carry weights reflecting the relative credibility of each alternative. The primary logic tree (`ssmLT_IND.xml`) contains three branch sets. [KB:source_model.md]^[Confidence: HIGH, Rationale: The logic tree structure and its epistemic uncertainty role are explicitly described in source_model.md ("Logic Tree Structure" section). The three branch set organisation and the branch weights are tabulated therein with no internal contradictions.]

Branch set 1 addresses source model selection (uncertainty type: `sourceModel`), applying to all sources. It offers three branches: `b1m1` selects the areal source model (`nt2012_areal_source_model_v1.xml`, weight 0.40); `b1m2` selects the smoothed-gridded model with $M_{\min}$ = 4.5 Mw (`nt2012_smoothed_source_model_v1_mmin4.5.xml`, weight 0.27); and `b1m3` selects the smoothed-gridded model with $M_{\min}$ = 5.5 Mw (`nt2012_smoothed_source_model_v1_mmin5.5.xml`, weight 0.33). The first branch represents the 108 areal seismogenic source zones; the second and third branches represent spatially smoothed point-source models distributed over the same grid domain but with different minimum magnitude thresholds. [KB:source_model.md][KB:site_sources_data.md]^[Confidence: HIGH, Rationale: Branch IDs, model filenames, and weights for branch set 1 are explicitly tabulated in source_model.md and confirmed in site_sources_data.md, which shows the same three branches with the same weights (0.40, 0.27, 0.33) as part of the site logic tree query for Rampura Agucha.]

Branch set 2 addresses $M_{\max}$ perturbation (uncertainty type: `maxMagGRRelative`), applying to all sources simultaneously. It contains three branches: `b2m1` applies a perturbation of $\Delta = -0.3$ Mw (weight 0.32), `b2m2` applies no perturbation ($\Delta = 0.0$ Mw, weight 0.36), and `b2m3` applies a perturbation of $\Delta = +0.3$ Mw (weight 0.32). [KB:source_model.md][KB:site_sources_data.md]^[Confidence: HIGH, Rationale: The $M_{\max}$ perturbation values and branch weights are explicitly tabulated in source_model.md and confirmed in site_sources_data.md for the Rampura Agucha site. The symmetric flanking weights (0.32) with a higher central weight (0.36) are consistent across both KB documents.]

Branch set 3 addresses $b$-value perturbation (uncertainty type: `bGRRelative`), applying to all sources simultaneously. It contains three branches: `b3m1` applies a perturbation of $\Delta = -0.1$ (weight 0.32), `b3m2` applies no perturbation ($\Delta = 0.0$, weight 0.36), and `b3m3` applies a perturbation of $\Delta = +0.1$ (weight 0.32). [KB:source_model.md][KB:site_sources_data.md]^[Confidence: HIGH, Rationale: The $b$-value perturbation values and branch weights are explicitly tabulated in source_model.md and confirmed in site_sources_data.md. The structure of the three branch sets is consistent with the description in ind-report.pdf.md, which also notes that epistemic uncertainty is addressed through alternative $b$ and $M_{\max}$ values.]

## SLOT 3: Earthquake Recurrence Parameters

Earthquake recurrence is described by a magnitude-frequency distribution (MFD) whose type and parameters are specified per source. All 108 area sources use the truncated Gutenberg-Richter distribution (`truncGutenbergRichterMFD`), parameterised by an $a$-value and a $b$-value with fixed $M_{\min}$ = 4.5 Mw and explicit $M_{\max}$ bounds. The smoothed point-source models inherit the same Gutenberg-Richter parametrisation from the parent areal zones, distributed over a regular spatial grid; no distinct $a$- or $b$-values are independently specified for individual point sources. [KB:source_model.md]^[Confidence: HIGH, Rationale: The MFD type, Mmin = 4.5 Mw, and the inheritance of GR parameters by point sources are all explicitly stated in source_model.md. The site-specific data for z919 and z932 in site_sources.md confirms Mmin = 4.5 Mw for the SCC zones at the project site.]

## SLOT 4: Magnitude-Frequency Distribution Types

The IND seismic source model employs a single MFD type across all sources: the truncated Gutenberg-Richter distribution (`truncGutenbergRichterMFD`). This parameterisation expresses earthquake occurrence rates using an $a$-value and a $b$-value, bounded by $M_{\min}$ and $M_{\max}$. The $a$-value controls the overall activity level (cumulative rate at the reference magnitude), and the $b$-value controls the slope of the log-linear frequency-magnitude relationship. The incremental (`incrementalMFD`), arbitrary (`arbitraryMFD`), and multi-valued (`multiMFD`) distribution types are not present in the IND model; all 108 area sources and all smoothed point-source models use the truncated Gutenberg-Richter form exclusively. [KB:source_model.md]^[Confidence: HIGH, Rationale: source_model.md explicitly states that all 108 area sources use truncGutenbergRichterMFD and provides the complete a- and b-value ranges. The absence of incrementalMFD or arbitraryMFD types is consistent with the model documentation, which describes only one MFD type throughout.]

Three magnitude-area scaling relationships are applied across different tectonic environments. The Wells and Coppersmith (1994) relationship (`WC1994`) [@Wells1994] is applied by 46 area sources in Active Shallow Crust and Stable Continental Crust settings. The Strasser et al. (2010) intraslab relationship (`StrasserIntraslab`) [@Strasser2010] is applied by 35 area sources in Subduction Intraslab settings. The Strasser et al. (2010) interface relationship (`StrasserInterface`) [@Strasser2010] is applied by 27 area sources in Subduction Interface settings. All area sources use a rupture aspect ratio of 2.0. [KB:source_model.md]^[Confidence: HIGH, Rationale: The three scaling relationships and their source counts are explicitly tabulated in source_model.md with corresponding @Wells1994 and @Strasser2010 citekeys. The total count (46 + 35 + 27 = 108) is internally consistent with the total number of area sources. The rupture aspect ratio of 2.0 is stated for all sources in the same document.]

## SLOT 5: Slip-Rate Data and Moment Balance

Activity rates for fault sources with available slip-rate data are derived from seismic-moment balance, where the seismic moment rate $\dot{M}_0$ is expressed as the product of shear modulus, fault area, and slip rate:^[Confidence: MEDIUM, Rationale: This introductory paragraph presents the standard seismic-moment balance framework as specified in the task. The equation is well-established in the seismological literature, but it is provided here as methodological context for a model that does not apply this approach. The KB does not contain any discussion of fault sources or moment-balance methods for the IND model, so this paragraph draws on disciplinary convention rather than KB evidence; MEDIUM confidence is assigned because the formula is unambiguous but its inclusion is contextual to a method not used in the IND model.]

$$\dot{M}_0 = \mu\, A\, S$$

where $\mu$ is the shear modulus, $A$ the fault area, and $S$ the long-term slip rate. The IND seismic source model contains no fault sources. No sources in the model carry slip-rate data; all 108 area sources and all smoothed-seismicity point sources derive their activity rates from empirical Gutenberg-Richter recurrence, with $a$- and $b$-values estimated from the earthquake catalogue rather than from seismic-moment balance. The number of sources with slip-rate data is therefore zero, and no slip-rate range is applicable within this model. [KB:source_model.md][KB:site_sources.md]^[Confidence: HIGH, Rationale: The absence of fault sources is stated explicitly in site_sources.md ("No fault sources are included in the IND source model") and is consistent with source_model.md, which describes only areaSource and pointSource types throughout, with no mention of faultSource, simpleFaultSource, or complexFaultSource. The purely empirical GR recurrence approach is confirmed throughout the KB.]

## SLOT 6: Maximum Magnitude Characterisation

Maximum magnitude ($M_{\max}$) defines the upper bound of the MFD for each source and is a critical parameter controlling the tail of the hazard curve. Epistemic uncertainty in $M_{\max}$ is captured through `maxMagGRRelative` logic-tree branch set 2, which applies simultaneous perturbations of $\Delta = -0.3$, $0.0$, and $+0.3$ Mw to all sources (weights 0.32, 0.36, 0.32). The derivation method for all area sources is the truncated Gutenberg-Richter MFD, with $M_{\max}$ assigned per zone from the source characterisation study by Nath and Thingbaijam [-@Nath2012]. For smoothed point-source models, $M_{\max}$ is inherited from the parent areal zone parametrisation; the same logic-tree perturbations apply to these sources. [KB:source_model.md]^[Confidence: HIGH, Rationale: The Mmax epistemic treatment via maxMagGRRelative branches (perturbations -0.3/0.0/+0.3 Mw, weights 0.32/0.36/0.32) is explicitly documented in source_model.md. The attribution to Nath and Thingbaijam (2012) is stated in the provenance section. The logic-tree structure is confirmed by site_sources_data.md for the Rampura Agucha site.]

## SLOT 7: Seismogenic Depth Parameters

Seismogenic depth parameters define the vertical extent within which earthquake ruptures are generated. Upper and lower seismogenic depths bound the rupture zone; hypocentral depth distributions, where specified, control the depth placement of point-source ruptures. The depth model reflects a multi-layer structure: shallow crustal sources (ASC and upper SCC) are confined to the top 25 km; intermediate-depth zones (lower SCC, upper SIF and SIS) extend to 70 km; and deep subduction intraslab zones reach 300 km depth. ## SLOT 8: Local Sources and Site Interrogation

All seismic sources surrounding and including the site in the areal source model belong to the Stable Continental Crust (SCC) tectonic region type, characteristic of intraplate continental settings with relatively low seismicity rates, moderate maximum magnitudes, and predominantly shallow-to-intermediate seismogenic depths. No subduction, active shallow crustal, or fault sources are present in the immediate vicinity of the site.
