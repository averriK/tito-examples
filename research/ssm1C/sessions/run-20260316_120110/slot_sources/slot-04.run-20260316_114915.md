## SLOT 4: Magnitude-Frequency Distribution Types

The IND seismic source model employs a single MFD type across all sources: the truncated Gutenberg-Richter distribution (`truncGutenbergRichterMFD`). This parameterisation expresses earthquake occurrence rates using an $a$-value and a $b$-value, bounded by $M_{\min}$ and $M_{\max}$. The $a$-value controls the overall activity level (cumulative rate at the reference magnitude), and the $b$-value controls the slope of the log-linear frequency-magnitude relationship. The incremental (`incrementalMFD`), arbitrary (`arbitraryMFD`), and multi-valued (`multiMFD`) distribution types are not present in the IND model; all 108 area sources and all smoothed point-source models use the truncated Gutenberg-Richter form exclusively. The absence of incrementalMFD or arbitraryMFD types is consistent with the model documentation, which describes only one MFD type throughout.]

Three magnitude-area scaling relationships are applied across different tectonic environments. The Wells and Coppersmith (1994) relationship (`WC1994`) [@Wells1994] is applied by 46 area sources in Active Shallow Crust and Stable Continental Crust settings. The Strasser et al. (2010) intraslab relationship (`StrasserIntraslab`) [@Strasser2010] is applied by 35 area sources in Subduction Intraslab settings. The Strasser et al. (2010) interface relationship (`StrasserInterface`) [@Strasser2010] is applied by 27 area sources in Subduction Interface settings. All area sources use a rupture aspect ratio of 2.0.
