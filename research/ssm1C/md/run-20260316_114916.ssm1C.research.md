# Seismic Source Model: Rampura Agucha Mine Tailings Storage Facility

## SLOT 1: SSM Overview and Source Census

The seismic source model (SSM) defines the spatial distribution, geometry, and earthquake occurrence rates of all seismogenic sources considered capable of contributing to ground-motion hazard at the site. The SSM is the principal input to the probabilistic seismic hazard analysis (PSHA) and is implemented in OpenQuake through a source-model logic tree (ssmLT) that captures epistemic uncertainty by assigning weights to alternative model configurations [KB:source_model.md].^[Confidence: HIGH, Rationale: The purpose and structure of the SSM are reproduced directly from the introductory section of KB:source_model.md; the description is consistent with standard PSHA methodology and contains no unsupported claims.]

The IND SSM is based on the probabilistic seismic hazard model for the Indian subcontinent developed by Nath and Thingbaijam [-@Nath2012], subsequently updated and translated into OpenQuake format in collaboration with Natural Resources Canada (version v2012.2.0), as documented in the GEM model report [-@GEM_IND]. The model domain extends from approximately $60.0^\circ$E to $100.8^\circ$E in longitude and $2.0^\circ$N to $40.0^\circ$N in latitude, covering India, Bangladesh, Bhutan, Nepal, Pakistan, Myanmar, and surrounding regions [KB:source_model.md][KB:ind-report.pdf.md]. The minimum earthquake magnitude ($M_{\min}$) adopted for hazard calculations is 4.5 Mw across the area source model; the two smoothed-seismicity grids employ $M_{\min}$ thresholds of 4.5 Mw and 5.5 Mw respectively [KB:source_model.md].^[Confidence: HIGH, Rationale: Model provenance, geographic extent, and Mmin values are explicitly stated in KB:source_model.md with cross-references to the GEM report; KB:ind-report.pdf.md corroborates the authors, version history, and tectonic summary. No ambiguity detected.]

The IND SSM comprises 443,197 seismic sources of two types: 108 area sources (`areaSource`) and 443,089 point sources (`pointSource`). These sources are classified into four tectonic region types: Subduction Intraslab (SIS, 139,977 sources), Subduction Interface (SIF, 123,775 sources), Stable Continental Crust (SCC, 94,450 sources), and Active Shallow Crust (ASC, 84,995 sources). The model is implemented through three logic-tree XML files: `ssmLT_IND.xml` (the primary tree with three branch sets, producing 27 end-branches), `ssmLT_IND_collapsed.xml` (a collapsed variant), and `ssmLT_IND_garage_v1.xml` (a full variant). The primary tree references three source-model branches [KB:source_model.md].^[Confidence: HIGH, Rationale: Source census figures, TRT breakdown, and logic-tree file identities are explicitly stated in KB:source_model.md. Arithmetic check: 139,977 + 123,775 + 94,450 + 84,995 = 443,197, consistent with the stated total. The 27 end-branches follow from $3 \times 3 \times 3 = 27$ across three branch sets of three branches each.]

Seismic-source characterisation follows the classical PSHA framework outlined by Cornell [-@Cornell1968] and formalised under SSHAC guidelines [-@SSHAC1997]. Sources are delineated from geologic, geophysical, and seismological evidence, with geometry and parametrisation defined in OpenQuake source-model XML files and encoded in the logic tree [KB:source_model.md].^[Confidence: HIGH, Rationale: Methodological attribution to Cornell (1968) and SSHAC (1997) is reproduced verbatim from KB:source_model.md with citekeys preserved; both references are well-established standard authorities in PSHA practice.]

## SLOT 2: Source-Model Logic Tree Structure

The source-model logic tree (`ssmLT_IND.xml`) encodes epistemic uncertainty through three branch sets, collectively producing $3 \times 3 \times 3 = 27$ end-branches. Each branch set addresses a distinct type of epistemic uncertainty; branches within each set carry weights reflecting the relative credibility of each alternative [KB:source_model.md].^[Confidence: HIGH, Rationale: Logic tree structure and end-branch count are stated explicitly in KB:source_model.md; $3^3 = 27$ is arithmetically correct and confirmed by KB:site_sources_data.md.]

Branch set 1 (uncertainty type `sourceModel`) contains three branches selecting alternative source-model representations of the seismicity. Branch set 2 (uncertainty type `maxMagGRRelative`) applies simultaneous relative perturbations to the maximum magnitude of all sources. Branch set 3 (uncertainty type `bGRRelative`) applies simultaneous relative perturbations to the Gutenberg-Richter $b$-value of all sources. The tables below list the branch IDs, perturbation values or model file identities, and assigned weights for each branch set [KB:source_model.md].^[Confidence: HIGH, Rationale: Uncertainty types for all three branch sets and the branch-level details are explicitly tabulated in KB:source_model.md with no ambiguity.]

| `b1m3` | `nt2012_smoothed_source_model_v1_mmin5.5.xml` | 0.33 |

## SLOT 3: Earthquake Recurrence Parameters

All 108 area sources in the IND model employ the truncated Gutenberg-Richter MFD (`truncGutenbergRichterMFD`), in which earthquake occurrence rates are parameterised by an $a$-value, a $b$-value, and explicit $M_{\min}$ and $M_{\max}$ bounds. The minimum magnitude $M_{\min}$ is 4.5 Mw for area sources in the shallow and intermediate tectonic regions; deep Subduction Intraslab (SIS) sources may adopt $M_{\min}$ up to 7.5 Mw. Epistemic uncertainty in the $b$-value is captured through logic-tree branch set 3, applying simultaneous relative perturbations of -0.1, 0.0, and +0.1 with weights 0.32, 0.36, and 0.32 [KB:source_model.md].^[Confidence: HIGH, Rationale: MFD type, Mmin range, and b-value epistemic branch details are stated explicitly in KB:source_model.md; the b-value branch set is confirmed in KB:site_sources_data.md.]

The two smoothed-seismicity point-source models do not carry independently specified $a$- or $b$-values at the individual point-source level; instead, they inherit their truncated GR parametrisation from the parent areal zone model, distributed spatially over a regular grid. The rate specification method for point sources is therefore one of spatial redistribution of the parent zone activity rather than independent catalogue fitting. ## SLOT 4: Magnitude-Frequency Distribution Types

The IND source model employs a single MFD type for all 108 area sources: the truncated Gutenberg-Richter distribution (`truncGutenbergRichterMFD`). Under this parametrisation, earthquake occurrence rates per unit magnitude are expressed as a log-linear function of magnitude, bounded at $M_{\min}$ and $M_{\max}$, and governed by the $a$-value (total activity rate intercept) and $b$-value (slope of the frequency-magnitude relation). No `incrementalMFD`, `arbitraryMFD`, or `multiMFD` source definitions are present in this model. The two smoothed-seismicity point-source grids share the same truncated GR formulation inherited from the parent areal zone model; distributed seismicity is handled entirely through GR parametrisation with no bin-by-bin rate specification [KB:source_model.md].^[Confidence: HIGH, Rationale: The enumeration of MFD types as exclusively truncGR for all area and point sources is stated without exception in KB:source_model.md. The absence of incrementalMFD/arbitraryMFD/multiMFD is consistent with the KB text, which identifies only truncGR for all 108 area sources.]

Three magnitude-area scaling relationships are applied across tectonic environments to relate moment magnitude to rupture dimensions [KB:source_model.md]. Wells and Coppersmith (1994) (`WC1994`) [@Wells1994] is applied to 46 area sources in Active Shallow Crust and Stable Continental Crust environments. The Strasser et al. (2010) intraslab relationship (`StrasserIntraslab`) [@Strasser2010] is applied to 35 area sources in Subduction Intraslab settings. The Strasser et al. (2010) interface relationship (`StrasserInterface`) [@Strasser2010] is applied to 27 area sources in Subduction Interface settings. The sum 46 + 35 + 27 = 108 accounts for all area sources, and all area sources adopt a rupture aspect ratio of 2.0 [KB:source_model.md].^[Confidence: HIGH, Rationale: Scaling relationship assignments, source counts, and tectonic environment designations are listed explicitly in KB:source_model.md with citekeys preserved from the KB passage. The sum 46 + 35 + 27 = 108 is arithmetically consistent with the total of 108 area sources.]

## SLOT 5: Slip-Rate Data and Moment Balance

Activity rates for fault sources with available slip-rate data are in principle derived from seismic-moment balance, where the seismic moment rate $\dot{M}_0$ is related to the shear modulus $\mu$, fault area $A$, and long-term slip rate $S$:^[Confidence: HIGH, Rationale: The seismic-moment balance equation and symbol definitions are as specified in the TASK_FILE framing for SLOT 5; the formulation is standard in PSHA fault-source characterisation and requires no external verification.]

$$\dot{M}_0 = \mu\, A\, S$$

The IND source model contains no fault sources. The complete source inventory consists exclusively of 108 areal seismogenic zones and 443,089 spatially distributed point sources in two smoothed-seismicity grids; no fault-source XML files are present, and no slip-rate data are specified for any source [KB:source_model.md][KB:site_sources.md]. Accordingly, the number of sources with slip-rate data is zero, and no slip-rate range can be reported for this model. Recurrence parameters for all area sources are instead derived from seismological catalogue statistics via Gutenberg-Richter fitting, as documented in the source-model XML files and the implementation report [-@Nath2012][-@GEM_IND] [KB:source_model.md].^[Confidence: HIGH, Rationale: The absence of fault sources is stated explicitly in KB:site_sources.md ("No fault sources are included in the IND source model") and is consistent with the source type enumeration in KB:source_model.md, which lists only areaSource and pointSource. The catalogue-based recurrence derivation is confirmed in KB:source_model.md and attributed to Nath and Thingbaijam (2012) via preserved citekeys.]

## SLOT 6: Maximum Magnitude Characterisation

For all 108 area sources, the base $M_{\max}$ values range from 6.0 to 9.4 Mw across the four tectonic region types. By TRT, the base $M_{\max}$ ranges are: ASC, 7.0-8.8 Mw; SCC, 6.0-8.2 Mw; SIF, 6.5-9.4 Mw; SIS, 6.5-8.6 Mw. The highest base values correspond to Subduction Interface zones, where great earthquakes exceeding $M$ 8.5 are considered possible. Epistemic uncertainty in $M_{\max}$ is applied uniformly to all sources through `maxMagGRRelative` logic-tree branch set 2, with perturbations of -0.3, 0.0, and +0.3 Mw and weights 0.32, 0.36, and 0.32 respectively. Applying these perturbations to the base range yields a model-wide low bound of 5.7-9.1 Mw, a central estimate of 6.0-9.4 Mw, and a high bound of 6.3-9.7 Mw [KB:source_model.md].^[Confidence: HIGH, Rationale: Base Mmax ranges by TRT, perturbation values, weights, and derived low/central/high bounds are all stated explicitly in KB:source_model.md. Arithmetic derivation of the bounds from base values and +-0.3 perturbation is consistent with the KB data.]

The derivation method for $M_{\max}$ across all area sources is the upper truncation of the truncated Gutenberg-Richter MFD; no independent magnitude-area relationship or geological derivation is applied separately for $M_{\max}$ estimation. Point sources in the two smoothed-seismicity grids do not carry independently constrained $M_{\max}$ values; their $M_{\max}$ is implicit, inherited from the parent areal zone model through the parametrisation transfer performed during grid generation [KB:source_model.md][KB:site_sources_data.md].^[Confidence: HIGH, Rationale: The truncGR upper-truncation as the derivation method and the inherited Mmax for point sources are stated in KB:source_model.md. KB:site_sources_data.md confirms that both smoothed-grid nearest sources carry a base Mmax of 6.5 Mw, consistent with the SCC zone z932 parametrisation, corroborating the inheritance mechanism.]

## SLOT 7: Seismogenic Depth Parameters

The seismogenic depth model in the IND SSM reflects a multi-layer structure consistent with the tectonic environment assigned to each source zone. Active Shallow Crust (ASC) sources are confined to the upper 25 km of the crust, with upper seismogenic depth $z_{\text{upper}}$ = 0 km, lower seismogenic depth $z_{\text{lower}}$ = 25 km, and mean hypocentral depth 15 km. Stable Continental Crust (SCC) sources span $z_{\text{upper}}$ = 0-25 km and $z_{\text{lower}}$ = 25-70 km, with mean hypocentral depths of 15-25 km. Subduction Interface (SIF) sources exhibit $z_{\text{upper}}$ = 0-70 km and $z_{\text{lower}}$ = 25-180 km, with mean hypocentral depths of 15-70 km. Subduction Intraslab (SIS) sources occupy the deepest zone, with $z_{\text{upper}}$ = 25-180 km, $z_{\text{lower}}$ = 70-300 km, and mean hypocentral depths of 25-180 km. Hypocentral depth distributions are specified as single-value distributions with probability 1.0 for all area sources [KB:source_model.md].^[Confidence: HIGH, Rationale: Depth parameters for all four TRTs are stated explicitly in the depth model table and accompanying text in KB:source_model.md. ## SLOT 8: Local Sources and Site Interrogation

The Rampura Agucha site ($74.7413^\circ$E, $25.8474^\circ$N) is located in Rajasthan within the Peninsular Indian shield. The site is contained within two overlapping areal seismogenic zones in the IND model: zone z919 (Peninsular India Layer 1, shallow SCC, depth 0-25 km) and zone z932 (Peninsular India Layer 2, intermediate SCC, depth 25-70 km). Both zones are present exclusively in the areal source model branch (weight 0.40) and are classified under the Stable Continental Crust (SCC) tectonic regime. No fault sources are included in the IND model. The two smoothed-seismicity grids provide the remaining source representation (combined weight 0.60), but their nearest point sources are located at 104.6 km and 114.1 km from the site, beyond the immediate site vicinity [KB:site_sources.md][KB:site_sources_data.md].^[Confidence: HIGH, Rationale: Site coordinates, zone identities (z919, z932), tectonic regime, areal branch weight, and smoothed-grid distances are all stated explicitly in KB:site_sources.md and confirmed in KB:site_sources_data.md. No unsupported claims.]

Both site-containing zones belong to the SCC tectonic regime, consistent with the stable intraplate character of Peninsular India. Zone z919 exhibits reverse faulting (nodal plane: strike $290^\circ$, dip $61^\circ$, rake $123^\circ$), carries a base $M_{\max}$ of 7.20 Mw (epistemic range 6.90-7.50 Mw), and is characterised by $a$ = 2.73, $b$ = 0.72, with seismogenic depths 0-25 km and mean hypocentral depth 15 km. Zone z932 exhibits sinistral strike-slip faulting (nodal plane: strike $239^\circ$, dip $67^\circ$, rake $8^\circ$), a base $M_{\max}$ of 6.50 Mw (range 6.20-6.80 Mw), $a$ = 4.15, $b$ = 0.93, and seismogenic depths 25-70 km with mean hypocentral depth 25 km. Based on these parameters, the seismic events most relevant to the immediate site vicinity are intraplate earthquakes in the $M_w$ 6.5-7.5 range, generated at shallow-to-intermediate crustal depths (15-25 km hypocentral), within a Stable Continental Crust setting characterised by reverse and strike-slip faulting mechanisms [KB:site_sources.md][KB:site_sources_data.md].^[Confidence: MEDIUM, Rationale: Zone parameters (faulting style, Mmax, depth, a/b values) for z919 and z932 are directly stated in KB:site_sources.md and confirmed in KB:site_sources_data.md. The characterisation of the relevant magnitude range as Mw 6.5-7.5 is a reasonable inference from the base Mmax values of z919 (7.20 Mw) and z932 (6.50 Mw) and their mean hypocentral depths; however, KB:site_sources_data.md explicitly notes that definitive controlling-source identification requires PSHA deaggregation, making this interpretation approximate rather than definitive.]
