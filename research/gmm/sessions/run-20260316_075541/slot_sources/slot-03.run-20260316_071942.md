## SLOT 3: Epistemic uncertainty and ground-motion logic trees

Epistemic uncertainty in ground-motion prediction is represented in PSHA through a ground-motion logic tree. Each branch of the tree corresponds to a candidate GMPE, and each branch is assigned a non-negative weight $w_k$. The weights are required to sum to unity across all $N$ branches in the tree:

$$\sum_{k=1}^{N} w_k = 1, \qquad w_k \geq 0$$

The mean hazard curve is computed as the weighted sum of the $N$ branch-specific hazard curves:

$$\lambda_{mean}(IM > im) = \sum_{k=1}^{N} w_k\, \lambda_k(IM > im)$$

where $\lambda_k$ is the annual exceedance rate computed using the $k$-th GMM. In addition to the mean hazard, the set of $N$ branch results constitutes a discrete approximation to the epistemic uncertainty distribution, from which fractile (quantile) hazard curves can be derived.^[Confidence: HIGH, Rationale: The logic tree formalism, the normalization condition, and the mean hazard calculation are standard PSHA methods implemented in OpenQuake and documented in the hazard literature. The KB files confirm that each logic tree in this assessment follows this structure [KB:gmmLT_ASC.md][KB:gmmLT_SCC.md][KB:gmmLT_SIF.md][KB:gmmLT_SIS.md].]

The structure of a ground-motion logic tree is organized hierarchically. At the top level, a separate logic tree is defined for each tectonic region type (TRT), reflecting the physical differences in source mechanism, wave propagation path, and site response among crustal, stable continental, and subduction tectonic environments. Within each TRT-level logic tree, one or more branching levels may be defined; in the present assessment each TRT tree contains a single branching level. At that branching level, a branch set is defined, and the candidate GMPEs are assigned as branches within the set. The branch weights within a set must satisfy the normalization condition and reflect the relative plausibility of the candidate models for that tectonic environment [KB:gmmLT_ASC.md][KB:gmmLT_SCC.md][KB:gmmLT_SIF.md][KB:gmmLT_SIS.md].^[Confidence: HIGH, Rationale: The hierarchical organization (logicTreeID, branchingLevelID, branchSetID, branches) is directly documented in the KB files for all four tectonic region types. The description is fully consistent with the NRML format and OpenQuake logic tree implementation.]

The assignment of weights to GMM branches encodes the analyst's judgment of the relative credibility of each model given the available evidence for the target region. Where region-specific strong-motion records are available in sufficient quantity, this judgment can be informed by quantitative performance metrics including log-likelihood scores, residual bias analyses, and inter-model distance measures. Where records are scarce or absent, the assignment of unequal weights would require an extra-evidential judgment that cannot be grounded in empirical observation; in this case, equal weighting is the epistemically conservative choice. The basis for equal weighting in the present assessment is discussed in the final section of this chapter.^[Confidence: MEDIUM, Rationale: The discussion of performance metrics (log-likelihood, residual bias) and the framing of equal weighting as epistemically conservative are consistent with the contemporary PSHA literature, including treatments of the ESHM20 craton model [DOI:10.1007/s10518-020-00940-x]. The specific characterization of equal weighting as the conservative choice in data-sparse contexts is a general principle rather than a directly cited result; MEDIUM confidence reflects this.]
