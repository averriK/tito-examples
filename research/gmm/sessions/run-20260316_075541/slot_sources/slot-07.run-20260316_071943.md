## SLOT 7: Subduction Intraslab (SIS) - GMPEs and logic tree

The logic tree for Subduction Intraslab carries the identifier `seed_SIS_modern` and is organised as a single branching level (`bl_SIS`, branch set `bs_SIS`) applied to all sources classified as SIS. The tree comprises ten branches, each assigned a weight of $0.10000$, summing to $1.00000$. The SIS ensemble largely parallels the SIF ensemble in model selection, with the substitution of slab-specific GSIM variants (e.g., `SSlab` suffix models in place of `SInter` variants) and the addition of `JaimesEtAl2020SSlab`. The KB does not document explicit per-model selection rationale for SIS.^[Confidence: HIGH, Rationale: Logic tree structure, weights, and identifiers confirmed directly from [KB:gmmLT_SIS.md].]

Abrahamson et al. (2018), implemented as `AbrahamsonEtAl2018SSlab`, is the BC Hydro intraslab GMPE, the slab component of the same BC Hydro model family used in the SIF logic tree. The model is calibrated for subduction intraslab earthquakes globally, with magnitude applicability from $M_w\ 5.0$ to approximately $8.0$ and rupture distances up to $500$ km. The OpenQuake implementation requires $R_{\text{rup}}$, $V_{S30}$, magnitude, and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIS.md]. BC Hydro intraslab regime and calibration range inferred from the BC Hydro model family documentation [DOI:10.1193/051712EQS188MR]; the $Z_{tor}$ requirement for the slab variant distinguishes it from the interface implementation.]

Abrahamson and Gulerce (2020), implemented as `AbrahamsonGulerce2020SSlab`, is the intraslab component of the NGA-Sub Abrahamson-Gulerce model, calibrated on 4,850 recordings from 89 intraslab events spanning $M_w\ 5.0$ to $7.8$. The model provides regional adjustments for seven subduction zones and requires $R_{\text{rup}}$, $V_{S30}$, magnitude, and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: HIGH, Rationale: Weight and parameter requirements from [KB:gmmLT_SIS.md]. Intraslab dataset size, magnitude range, and regional structure confirmed from external search [WEB:https://peer.berkeley.edu/publications/2020-25].]

Atkinson (2022), implemented as `Atkinson2022SSlab`, is the intraslab backbone GMPE for the NZ22 model set. The implementation requires $R_{\text{rup}}$; site parameters $V_{S30}$ and a back-arc classification flag; and magnitude. The back-arc flag is needed because intraslab attenuation differs systematically between forearc and backarc paths. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements including the back-arc flag from [KB:gmmLT_SIS.md]; NZ22 membership confirmed by hazardlib source path. Intraslab calibration specifics inferred from the NZ22 programme context.]

Chao et al. (2020), implemented as `ChaoEtAl2020SSlab`, is the intraslab component of the Taiwan-focused Chao et al. model. The implementation requires $R_{\text{rup}}$; site parameters $V_{S30}$, measured-$V_{S30}$ flag, and $Z_{1.0}$; and rupture parameters magnitude and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIS.md]. Publication context from [WEB:https://journals.sagepub.com/doi/abs/10.1177/8755293019891711].]

Jaimes and Garcia-Soto (2020), implemented as `JaimesEtAl2020SSlab`, is an updated GMPE for intermediate-depth intraslab earthquakes in Mexico on the Cocos plate subduction system. The model is calibrated using 366 accelerogram records from 23 events, extended with additional records from 2005 to 2017, and covers magnitudes from approximately $M_w\ 5.0$ to $7.8$. The implementation requires both hypocentral distance $R_{\text{hypo}}$ and $R_{\text{rup}}$, along with $V_{S30}$, hypocentral depth, and magnitude. The assigned weight is $0.10000$.^[Confidence: HIGH, Rationale: Weight and parameter requirements from [KB:gmmLT_SIS.md]. Dataset details, magnitude range, and Mexican intraslab calibration confirmed from external search [WEB:https://journals.sagepub.com/doi/10.1177/8755293019899947].]

Kuehn et al. (2020), implemented as `KuehnEtAl2020SSlab`, is the intraslab component of the partially non-ergodic NGA-Sub Kuehn model, using the same Bayesian regression framework as the interface variant but calibrated on intraslab records from the NGA-Sub database. The OpenQuake implementation requires $R_{\text{rup}}$, $V_{S30}$, magnitude, and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: HIGH, Rationale: Weight and parameter requirements from [KB:gmmLT_SIS.md]. Bayesian NGA-Sub framework confirmed from external search [WEB:https://peer.berkeley.edu/publications/2020-04].]

Montalva et al. (2017), implemented as `MontalvaEtAl2017SSlab`, is the intraslab component of the Chilean subduction model by Montalva et al. The implementation requires hypocentral distance $R_{\text{hypo}}$; site parameters $V_{S30}$ and a back-arc classification flag; and rupture parameters hypocentral depth and magnitude. The use of hypocentral distance rather than rupture distance reflects the point-source geometry typical of deep intraslab events. The assigned weight is $0.10000$.^[Confidence: HIGH, Rationale: Weight and parameter requirements (including back-arc and hypocentral distance) confirmed from [KB:gmmLT_SIS.md]. Chilean subduction calibration from [DOI:10.1785/0120160048]. The parameter differences between the SIF and SIS Montalva implementations (rrup vs. rhypo; different site parameters) are directly observable in the KB.]

Parker et al. (2020), implemented as `ParkerEtAl2020SSlab`, is the intraslab component of the NGA-Sub Parker model, calibrated for intraslab earthquakes at magnitudes $M_w\ 5.0$ to $7.8$ with regional adjustment factors. The implementation requires $R_{\text{rup}}$, $V_{S30}$, hypocentral depth, and magnitude. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIS.md]. NGA-Sub programme context from [WEB:https://peer.berkeley.edu/publications/2020-03].]

Phung et al. (2020), implemented as `PhungEtAl2020SSlab`, is the intraslab component of the Taiwan Phung model. The implementation requires $R_{\text{rup}}$; site parameters $V_{S30}$ and $Z_{1.0}$; and rupture parameters magnitude and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIS.md]. Publication context from [WEB:https://journals.sagepub.com/doi/abs/10.1177/87552930211061168].]

Si et al. (2020), implemented as `SiEtAl2020SSlab`, is the intraslab component of the West Sumatra Si et al. regional model, calibrated on intraslab records from the BMKG network spanning approximately $M_w\ 4.1$ to $6.5$ and hypocentral distances from $17$ to $1{,}000$ km. The implementation requires $R_{\text{rup}}$; site parameters $V_{S30}$ and $Z_{2.5}$; and rupture parameters hypocentral depth and magnitude. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIS.md]. Magnitude range and Sumatra calibration from external search [WEB:https://www.e3s-conferences.org/articles/e3sconf/pdf/2020/16/e3sconf_iceedm2020_03001.pdf].]
