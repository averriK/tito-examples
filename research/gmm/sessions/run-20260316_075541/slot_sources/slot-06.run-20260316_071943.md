## SLOT 6: Subduction Interface (SIF) - GMPEs and logic tree

The logic tree for Subduction Interface carries the identifier `seed_SIF_modern` and is organised as a single branching level (`bl_SIF`, branch set `bs_SIF`) applied to all sources classified as SIF. The tree comprises ten branches, each assigned a weight of $0.10000$, summing to $1.00000$. The structure mirrors the ASC logic tree in its uniform ten-branch design. The KB does not document explicit per-model selection rationale for this tectonic region type.^[Confidence: HIGH, Rationale: Logic tree structure, weights, and identifiers confirmed directly from [KB:gmmLT_SIF.md].]

Abrahamson et al. (2018), implemented as `AbrahamsonEtAl2018SInter`, is the BC Hydro subduction interface GMPE, representing a revision of the Abrahamson, Gregor and Addo (2016) model developed for the BC Hydro seismic hazard programme. The model is calibrated for subduction interface earthquakes globally, covering magnitudes from $M_w\ 5.0$ to approximately $9.5$ and rupture distances up to $500$ km. The OpenQuake implementation requires $R_{\text{rup}}$, $V_{S30}$, and magnitude. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIF.md]. BC Hydro model calibration range and subduction regime are documented in [DOI:10.1193/051712EQS188MR] (2016 base model); the 2018 revision details should be verified against the updated BC Hydro report.]

Abrahamson and Gulerce (2020), implemented as `AbrahamsonGulerce2020SInter`, is a regionalized subduction interface GMPE developed under the NGA-Subduction programme using the NGA-Sub database of 3,914 recordings from 113 interface events. The model covers magnitudes $M_w\ 5.0$ to $9.2$ and rupture distances up to $500$ km (extended to $800$ km in the Cascadia backarc region), with region-specific adjustments for seven subduction zones. The OpenQuake implementation requires $R_{\text{rup}}$, $V_{S30}$, and magnitude. The assigned weight is $0.10000$.^[Confidence: HIGH, Rationale: Weight and parameter requirements from [KB:gmmLT_SIF.md]. Calibration details (dataset size, magnitude range, distance range, seven regions) confirmed from external search [WEB:https://peer.berkeley.edu/publications/2020-25].]

Atkinson (2022), implemented as `Atkinson2022SInter`, is the subduction interface backbone GMPE for the NZ22 model set, employing equivalent point-source concepts adapted for subduction interface conditions in New Zealand. The implementation requires $R_{\text{rup}}$, $V_{S30}$, and magnitude. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIF.md]; NZ22 membership confirmed by source path `nz22/atkinson_2022.py`. Calibration specifics for the interface component are inferred from the broader NZ22 documentation.]

Atkinson and Macias (2009), modified for the 2014 National Seismic Hazard Mapping Program (NSHMP), implemented as `AtkinsonMacias2009NSHMP2014`, is a subduction interface GMPE developed for the Cascadia subduction zone targeting great interface earthquakes ($M_w\ 8.3$ to $9.5$) at rupture distances up to approximately $300$ km. The NSHMP 2014 modification adjusts the median predictions for use in the conterminous United States national hazard model. The OpenQuake implementation requires $R_{\text{rup}}$ and magnitude only, with no site term included in the hazardlib implementation. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIF.md]; source path `can15/sinter.py` confirms the Canadian seismic hazard model provenance. Magnitude range and Cascadia focus are from external knowledge of the Atkinson-Macias 2009 model.]

Chao et al. (2020), implemented as `ChaoEtAl2020SInter`, is the subduction interface component of a combined crustal and subduction GMPE calibrated for Taiwan. The implementation requires $R_{\text{rup}}$; site parameters $V_{S30}$, measured-$V_{S30}$ flag, and $Z_{1.0}$; and rupture parameters magnitude and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIF.md]. The Chao et al. (2020) Taiwan-focused subduction model is referenced in external search [WEB:https://journals.sagepub.com/doi/abs/10.1177/8755293019891711]; specific interface calibration details are not fully resolved from available external sources.]

Kuehn et al. (2020), implemented as `KuehnEtAl2020SInter`, is a partially non-ergodic subduction interface GMPE developed under the NGA-Subduction programme, employing Bayesian regression with informative priors over the NGA-Sub database of more than 210,000 ground-motion components from 1,570 events spanning $M_w\ 4.0$ to $9.1$. The model provides region-specific constants, anelastic attenuation, and site amplification parameters for seven global subduction zones. The OpenQuake implementation requires $R_{\text{rup}}$, $V_{S30}$, magnitude, and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: HIGH, Rationale: Weight and parameter requirements from [KB:gmmLT_SIF.md]. Dataset size, magnitude range, and Bayesian framework confirmed from external search [WEB:https://peer.berkeley.edu/publications/2020-04].]

Montalva et al. (2017), implemented as `MontalvaEtAl2017SInter`, is a subduction interface GMPE calibrated specifically on Chilean strong-motion data, covering subduction interface events from $M_w\ 5.0$ to approximately $8.8$ and rupture distances up to $400$ km. The model requires $R_{\text{rup}}$; site parameters $V_{S30}$ and a back-arc classification flag; and magnitude as a rupture parameter. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIF.md]. Chilean subduction calibration and magnitude range are from the published model [DOI:10.1785/0120160048]; the back-arc parameter requirement is confirmed from the hazardlib attribute declarations in the KB.]

Parker et al. (2020), implemented as `ParkerEtAl2020SInter`, is a global subduction interface GMPE developed under the NGA-Subduction programme using a combined global database. The model covers interface earthquakes from $M_w\ 5.0$ to $9.2$ and is designed with regional adjustment factors. The OpenQuake implementation requires $R_{\text{rup}}$, $V_{S30}$, and magnitude. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIF.md]. NGA-Sub programme context and magnitude range from external search [WEB:https://peer.berkeley.edu/publications/2020-03].]

Phung et al. (2020), implemented as `PhungEtAl2020SInter`, is the subduction interface component of the Phung et al. Taiwan model. The OpenQuake implementation requires $R_{\text{rup}}$; site parameters $V_{S30}$ and $Z_{1.0}$; and rupture parameters magnitude and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIF.md]. Publication context from external search [WEB:https://journals.sagepub.com/doi/abs/10.1177/87552930211061168].]

Si et al. (2020), implemented as `SiEtAl2020SInter`, is a regional ground-motion model for subduction interface earthquakes calibrated on 375 strong-motion records from the BMKG accelerograph network in West Sumatra, covering approximately $M_w\ 4.0$ to $6.4$ and hypocentral distances from approximately $17$ to $1{,}000$ km. The OpenQuake implementation requires $R_{\text{rup}}$; site parameters $V_{S30}$ and $Z_{2.5}$; and rupture parameters hypocentral depth and magnitude. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SIF.md]. Dataset size, magnitude range, and Sumatra regional calibration are from external search [WEB:https://www.e3s-conferences.org/articles/e3sconf/pdf/2020/16/e3sconf_iceedm2020_03001.pdf].]
