## SLOT 5: Stable Continental Crust (SCC) - GMPEs and logic tree

The SCC logic tree bears the identifier `seed_SCC_modern` and is organized under branching level `bl_SCC` and branch set `bs_SCC`. It comprises six branches. Five branches carry weight $w_k = 0.16667$ and the sixth branch (`CollapsedNGAEastUSGS`) carries a residual weight of $0.16665$, making the weighting quasi-uniform with total weight summing to $1.00000$. A runtime HDF5 table (`NGAEastUSGS_collapsed.hdf5`) is associated with the sixth branch. The SCC tree contains fewer branches than the ASC, SIF, and SIS trees, reflecting the more limited number of GMPEs calibrated directly for stable continental regions. The supporting documentation does not state an explicit model-by-model rationale for selection. The first SCC branch is Atkinson (2008, prime version) (`Atkinson2008prime`), a GMPE for Eastern North America (ENA) representing a modified version of the Atkinson (2008) referenced empirical model for stable continental crust. The model is calibrated for the SCC regime. In the OpenQuake hazard library the implementation, accessed through the `boore_atkinson_2011.py` module, requires $R_{jb}$, $V_{S30}$, and the rupture parameters magnitude and rake. The assigned weight is $0.16667$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SCC.md]^[Confidence: HIGH, Rationale: Branch name, weight, module path, and all parameter requirements are directly confirmed by the KB. The ENA/SCC classification of the Atkinson (2008) prime model is well established in the stable continental GMPE literature.]

The second branch is Atkinson and Boore (2006), modified in 2011, (`AtkinsonBoore2006Modified2011`), a hybrid empirical GMPE calibrated for Eastern North America. The original model used NGA-West2 host-region GMPEs scaled to ENA conditions; the 2011 modification introduced adjustments for improved calibration. In the OpenQuake hazard library it requires $R_{rup}$, $V_{S30}$, and moment magnitude. The assigned weight is $0.16667$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SCC.md]^[Confidence: HIGH, Rationale: Branch name, weight, and all parameter requirements are directly confirmed by the KB. The ENA hybrid empirical calibration approach for Atkinson and Boore (2006) modified in 2011 is well established in the stable continental GMPE literature.]

The third branch is Pezeshk et al. (2011) (`PezeshkEtAl2011`), a hybrid empirical GMPE for Central and Eastern North America (CENA) calibrated for the stable continental crust regime. The model does not require a site parameter in the current OpenQuake hazard library implementation; it uses only $R_{rup}$ and moment magnitude as predictors. The assigned weight is $0.16667$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SCC.md]^[Confidence: HIGH, Rationale: Branch name, weight, and the parameter requirements (rrup and mag only, no site parameter) are directly confirmed by the KB. The CENA/SCC hybrid empirical calibration of Pezeshk et al. (2011) is well established.]

The fourth branch is ESHM20Craton (`ESHM20Craton`), the craton-specific GMPE component of the 2020 European Seismic Hazard Model, calibrated for stable cratonic environments. In the OpenQuake hazard library it requires $R_{rup}$, $V_{S30}$, and moment magnitude. The assigned weight is $0.16667$. The supporting documentation does not state a model-specific selection rationale beyond SCC applicability. The fifth branch is Somerville et al. (2009) Yilgarn Craton model with SS14 sigma (`SomervilleEtAl2009YilgarnCraton_SS14`), a GMPE calibrated for the stable cratonic environment of the Yilgarn Craton in Western Australia. The SS14 designation indicates that the standard deviation model has been updated to the Seyhan and Stewart (2014) formulation. In the OpenQuake hazard library it requires $R_{jb}$, $V_{S30}$, and moment magnitude. The assigned weight is $0.16667$. The supporting documentation does not state a model-specific selection rationale. The sixth branch is CollapsedNGAEastUSGS (`CollapsedNGAEastUSGS`), a custom GSIM registered in the project's `gmm.gmpe` extension module. This implementation extends the OpenQuake `NGAEastUSGSGMPE` base class and collapses the ensemble of 17 NGA-East USGS median ground motion models into a single GSIM by inflating the total sigma with a stored between-model uncertainty term read from the runtime HDF5 table. The underlying NGA-East models were developed for Central and Eastern North America using a comprehensive SSHAC Level 3 process, covering $M_w$ in the range 4.0 to 8.2 at distances up to approximately 1500 km. In the OpenQuake hazard library the collapsed implementation requires only $V_{S30}$ and moment magnitude, without an explicit distance predictor column. The assigned weight is $0.16665$. The supporting documentation does not state a model-specific selection rationale beyond SCC classification. The NGA-East Mw 4.0-8.2 range and CENA applicability are confirmed by the USGS web source.]
