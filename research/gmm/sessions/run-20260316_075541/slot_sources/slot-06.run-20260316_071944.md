## SLOT 6: Subduction Interface (SIF) - GMPEs and logic tree

The SIF logic tree bears the identifier `seed_SIF_modern` and is organized under branching level `bl_SIF` and branch set `bs_SIF`. It comprises ten branches, each assigned equal weight $w_k = 0.10000$, with total weight summing to $1.00000$. The uniform weighting reflects the equal epistemic standing of all ten GMPEs in the absence of region-specific observational data sufficient to discriminate among them. The supporting documentation does not state an explicit model-by-model selection rationale. [KB:gmmLT_SIF.md]^[Confidence: HIGH, Rationale: All logic tree identifiers, branch count, uniform weights, and total weight are directly confirmed in the KB document gmmLT_SIF.md.]

The first SIF branch is Abrahamson et al. (2018) for subduction interface (`AbrahamsonEtAl2018SInter`), an update to the BC Hydro subduction GMPE using the NGA-Subduction dataset, published as PEER Report 2018/02. The model is calibrated for global subduction interface events with $M_w$ approximately 6.0 to 9.0 and $R_{rup}$ up to approximately 300 km. In the OpenQuake hazard library it requires $R_{rup}$, $V_{S30}$, and moment magnitude. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. The second branch is Abrahamson and Gulerce (2020) for subduction interface (`AbrahamsonGulerce2020SInter`), a NGA-Subduction model for global subduction zones. The model is calibrated for subduction interface events. In the OpenQuake hazard library it requires $R_{rup}$, $V_{S30}$, and moment magnitude. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. The third branch is Atkinson (2022) for subduction interface (`Atkinson2022SInter`), the NZ22 subduction interface backbone model, implemented through the same `nz22/atkinson_2022.py` module as the crustal variant. The model is calibrated for subduction interface events and requires $R_{rup}$, $V_{S30}$, and moment magnitude in the OpenQuake hazard library. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. The fourth branch is Atkinson and Macias (2009) as implemented in the 2014 US National Seismic Hazard Model (`AtkinsonMacias2009NSHMP2014`), a simulation-based GMPE for Cascadia subduction interface earthquakes published in the Bulletin of the Seismological Society of America. The model was calibrated for large interface events in the magnitude range $M_w$ 7.5 to 9.0 using stochastic simulations anchored to recordings from the 2003 Tokachi-Oki earthquake sequence in Japan, with subsequent adjustments for Cascadia source and attenuation conditions. In the OpenQuake hazard library it requires $R_{rup}$ and moment magnitude, without a separate site velocity parameter. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SIF.md][WEB:https://pubs.geoscienceworld.org/ssa/bssa/article-abstract/99/3/1552/350126]^[Confidence: HIGH, Rationale: Branch name, weight, and parameter requirements (rrup and mag only) are directly confirmed by the KB. The fifth branch is Chao et al. (2020) for subduction interface (`ChaoEtAl2020SInter`), the interface variant of the Taiwan-origin subduction GMPE. In the OpenQuake hazard library it requires $R_{rup}$; the site parameters $V_{S30}$, a $V_{S30}$ measurement flag, and $z_{1.0}$; and the rupture parameters magnitude and $z_{tor}$. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale beyond SIF classification. [KB:gmmLT_SIF.md]^[Confidence: HIGH, Rationale: Branch name, weight, and all parameter requirements are directly confirmed by the KB.]

The sixth branch is Kuehn et al. (2020) for subduction interface (`KuehnEtAl2020SInter`), a partially non-ergodic NGA-Sub model published as PEER Report 2020/04. The model is calibrated for global subduction zones through a regionalized framework encompassing seven regional subsets: Alaska, Central America and Mexico, Cascadia, Japan, New Zealand, South America, and Taiwan. In the OpenQuake hazard library it requires $R_{rup}$, $V_{S30}$, and the rupture parameters magnitude and $z_{tor}$. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SIF.md][WEB:https://peer.berkeley.edu/publications/2020-04]^[Confidence: HIGH, Rationale: Branch name, weight, and parameter requirements are directly confirmed by the KB. The seventh branch is Montalva et al. (2017) for subduction interface (`MontalvaEtAl2017SInter`), a GMPE for the Chilean subduction zone published in the Bulletin of the Seismological Society of America. The model was calibrated using 3774 recordings from 473 earthquakes recorded in Chile between 1985 and 2015, covering $M_w$ in the range 4.6 to 8.8 and $R_{rup}$ from approximately 20 to 650 km. In the OpenQuake hazard library it requires $R_{rup}$, the site parameters $V_{S30}$ and a backarc flag, and moment magnitude. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. The eighth branch is Parker et al. (2020) for subduction interface (`ParkerEtAl2020SInter`), a global NGA-Sub model published as PEER Report 2020/03 and subsequently in Earthquake Spectra (2022). The model draws on records from subduction zones in Japan, Taiwan, New Zealand, Mexico, Central America, South America, Alaska, and Cascadia, and is calibrated for interface events with $M_w$ in the range 4.7 to 9.1 and $R_{rup}$ from approximately 25 to 2000 km. In the OpenQuake hazard library it requires $R_{rup}$, $V_{S30}$, and moment magnitude. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale.
