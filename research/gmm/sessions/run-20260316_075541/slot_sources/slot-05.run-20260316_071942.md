## SLOT 5: Stable Continental Crust (SCC) - GMPEs and logic tree

The SCC ground-motion logic tree (logicTreeID: seed_SCC_modern) is organized at a single branching level (branchingLevelID: bl_SCC) containing one branch set (branchSetID: bs_SCC), applied to the tectonic region type SCC. Six branches are included with quasi-uniform weighting: five branches carry weight 0.16667 each and the CollapsedNGAEastUSGS branch carries the residual weight 0.16665, for a total of 1.00000 [KB:gmmLT_SCC.md]. As with the other logic trees, the KB does not document explicit per-model selection justifications.^[Confidence: HIGH, Rationale: Tree structure, identifiers, branch count, and weights are taken directly from [KB:gmmLT_SCC.md] and are authoritative.]

The Atkinson2008prime branch (weight 0.16667) is a modified form of the Atkinson (2008) stable continental GMM for Central and Eastern North America, updated by the magnitude-dependent stress-drop scaling factor proposed by Atkinson and Boore (2011) in the Bulletin of the Seismological Society of America, which introduced adjustments to short-period predictions in response to newly available data [WEB:https://docs.openquake.org/old/oq-hazardlib/0.16/gsim/atkinson_boore_2006.html]. The model is calibrated for the stable continental Eastern North American environment. The hazardlib implementation, contained in `boore_atkinson_2011.py`, requires $R_{JB}$, $V_{S30}$, magnitude, and rake [KB:gmmLT_SCC.md].^[Confidence: MEDIUM, Rationale: The association with the Atkinson (2008) model updated per Atkinson & Boore (2011) is consistent with the OQ documentation web search result and the source file path in [KB:gmmLT_SCC.md]. A specific DOI for the 2008 Atkinson SCC model was not confirmed; MEDIUM confidence reflects this gap.]

The AtkinsonBoore2006Modified2011 branch (weight 0.16667) is based on the Atkinson and Boore (2006) GMM for Eastern North America, which was derived from stochastic simulations of ground motion for stable continental conditions calibrated for M 3-8 at distances up to approximately 1000 km, and subsequently modified per Atkinson and Boore (2011) [WEB:https://docs.openquake.org/old/oq-hazardlib/0.16/gsim/atkinson_boore_2006.html]. The model is specifically applicable to the stable continental Eastern North American regime. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, and magnitude [KB:gmmLT_SCC.md].^[Confidence: MEDIUM, Rationale: The model origin (Eastern North America, stochastic simulations, 2006 with 2011 modifications) and calibration range are consistent with the OQ documentation search result. A formal journal DOI was not confirmed in the web search; MEDIUM confidence reflects partial verification.]

The PezeshkEtAl2011 branch (weight 0.16667) corresponds to the hybrid empirical GMM for Eastern North America developed by Pezeshk, Zandieh, and Tavakoli (2011), which combines NGA-West1 model predictions with stochastic ground-motion simulations adjusted to Eastern North American source and attenuation parameters, published in the Bulletin of the Seismological Society of America [DOI:10.1785/0120100082]. The model is calibrated for stable continental conditions over M 4-8 at distances up to 1000 km. The hazardlib implementation requires only $R_{rup}$ and magnitude, with no site amplification term [KB:gmmLT_SCC.md].^[Confidence: HIGH, Rationale: The DOI, hybrid empirical methodology, calibration range (M4-8, up to 1000 km), and the absence of a site amplification term are confirmed by the web search result. Hazardlib parameters are from [KB:gmmLT_SCC.md].]

The ESHM20Craton branch (weight 0.16667) is the regionally adjustable backbone model for stable continental (craton) regions developed by Weatherill and Cotton (2020), published in the Bulletin of Earthquake Engineering as part of the 2020 European Seismic Hazard Model [DOI:10.1007/s10518-020-00940-x]. The model is constructed by adapting Eastern North American GMPEs through a scaled backbone approach to characterize epistemic uncertainty in European craton ground motion. It is calibrated for stable cratonic conditions. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, and magnitude [KB:gmmLT_SCC.md].^[Confidence: HIGH, Rationale: The DOI, authors, publication venue (BEE), and the craton-backbone methodology are confirmed by the web search results. Hazardlib parameters are from [KB:gmmLT_SCC.md].]

The SomervilleEtAl2009YilgarnCraton_SS14 branch (weight 0.16667) is based on Somerville et al. (2009), a simulation-based GMM for the Yilgarn Craton of Western Australia developed using broadband strong-motion simulations calibrated to regional crustal velocity models, applied here with SS14 site adjustment factors [WEB:https://www.aees.org.au/wp-content/uploads/2013/11/Somerville-et-al.pdf]. The model is calibrated for cratonic Australian conditions and predicts enhanced long-period ground motion associated with surface waves trapped in shallow low-velocity surface layers. The hazardlib implementation requires $R_{JB}$, $V_{S30}$, and magnitude [KB:gmmLT_SCC.md].^[Confidence: MEDIUM, Rationale: The Somerville et al. (2009) Yilgarn Craton model is confirmed by the web search result referencing the AEES publication and Geoscience Australia report. The SS14 designation is present in the KB model name but the specific SS14 site adjustment procedure is not further described in the available sources. MEDIUM confidence reflects the absence of a formal DOI.]

The CollapsedNGAEastUSGS branch (weight 0.16665) is a custom GSIM registered via `gmm.gmpe` that extends the NGAEastUSGSGMPE class, representing the full suite of 13 NGA-East USGS ground-motion models (Goulet et al. 2017) as a single collapsed model [WEB:https://peer.berkeley.edu/new-peer-report-201703]. The collapse precomputes model predictions into a runtime HDF5 lookup table (`NGAEastUSGS_collapsed.hdf5`) and inflates the total sigma by a stored between-model epistemic term, accounting for the spread among the constituent NGA-East models within a single logic tree branch [KB:gmmLT_SCC.md]. The NGA-East USGS suite is calibrated for Central and Eastern North American stable continental conditions over M 4-8.2 at distances up to 1500 km. The hazardlib implementation requires $V_{S30}$ and magnitude; no explicit distance parameter is listed, as distance enters the model internally through the precomputed lookup table [KB:gmmLT_SCC.md].^[Confidence: MEDIUM, Rationale: The NGA-East USGS context and PEER Report 2017/03 are confirmed by web search. The technical collapse mechanism (HDF5 table, between-model sigma inflation) is taken from [KB:gmmLT_SCC.md] and treated as authoritative. The calibration range (M4-8.2, up to 1500 km) is from the NGA-East USGS suite description in the web search. The absence of requires_distances in the KB is taken at face value; MEDIUM confidence reflects the non-standard implementation.]
