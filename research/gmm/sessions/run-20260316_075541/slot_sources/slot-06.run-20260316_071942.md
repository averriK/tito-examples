## SLOT 6: Subduction Interface (SIF) - GMPEs and logic tree

The SIF ground-motion logic tree (logicTreeID: seed_SIF_modern) is organized at a single branching level (branchingLevelID: bl_SIF) containing one branch set (branchSetID: bs_SIF), applied to the tectonic region type SIF. Ten branches are included, each carrying equal weight 0.10000, for a total weight of 1.00000. All ten models are calibrated for subduction interface conditions, and all hazardlib implementations use $R_{rup}$ as their primary distance metric [KB:gmmLT_SIF.md].^[Confidence: HIGH, Rationale: Tree structure, identifiers, weights, and the universal Rrup distance metric are taken directly from [KB:gmmLT_SIF.md] and are authoritative.]

The AbrahamsonEtAl2018SInter branch (weight 0.10000) is the interface variant of the BC Hydro GMM published by Abrahamson, Gregor, and Addo (2016) in Earthquake Spectra, calibrated from 953 recordings of 43 interface events spanning M 6.0-8.4 at distances up to 300 km from global subduction zones, with magnitude scaling constrained by numerical simulations above M 8.0 [DOI:10.1193/051712EQS188MR]. The model is calibrated for global subduction interface settings. The hazardlib implementation requires $R_{rup}$ and $V_{S30}$ [KB:gmmLT_SIF.md].^[Confidence: HIGH, Rationale: DOI, calibration dataset (953 recordings, 43 events, M6.0-8.4, up to 300 km), and the simulation-based constraint above M8.0 are confirmed by web search. Hazardlib parameters are from [KB:gmmLT_SIF.md].]

The AbrahamsonGulerce2020SInter branch (weight 0.10000) is the interface component of the NGA-Subduction regionalized GMM by Abrahamson and Gulerce (2020), developed as PEER Report 2020/25, calibrated from 3914 recordings of 113 interface events spanning M 5-9.2 from the NGA-SUB global database, with region-specific adjustments for seven subduction zones [DOI:10.1177/87552930221114374]. The model is calibrated for global interface conditions with regional adjustments. The hazardlib implementation requires $R_{rup}$ and $V_{S30}$ [KB:gmmLT_SIF.md].^[Confidence: HIGH, Rationale: DOI, calibration statistics (3914 recordings, 113 events, M5-9.2, seven regions), and PEER report origin are confirmed by web search. Hazardlib parameters are from [KB:gmmLT_SIF.md].]

The Atkinson2022SInter branch (weight 0.10000) is the subduction interface backbone model by Atkinson (2022) developed for the 2022 New Zealand NSHM, applying an equivalent point-source framework adapted to interface earthquake kinematics, with the New Zealand database providing empirical constraints over approximately M 4-7 at distances up to approximately 400 km [WEB:https://pubs.geoscienceworld.org/ssa/bssa/article-abstract/114/1/350/631700/Backbone-Ground-Motion-Models-for-Crustal]. The model is calibrated for the New Zealand subduction interface setting. It requires $R_{rup}$, $V_{S30}$, and magnitude [KB:gmmLT_SIF.md].^[Confidence: HIGH, Rationale: NZ22 context and calibration range confirmed by web search. Hazardlib parameters from [KB:gmmLT_SIF.md].]

The AtkinsonMacias2009NSHMP2014 branch (weight 0.10000) is based on the Atkinson and Macias (2009) subduction interface model as implemented for the 2014 Canadian National Seismic Hazard Model, designed for Cascadia and equivalent subduction interface environments. The hazardlib implementation, contained in `can15/sinter.py`, requires $R_{rup}$ and magnitude only, with no explicit site parameter [KB:gmmLT_SIF.md].^[Confidence: MEDIUM, Rationale: The Cascadia applicability and Canadian NSHM origin are inferred from the source file path (can15/sinter.py) and the NSHMP2014 suffix. An explicit DOI for the Atkinson & Macias (2009) base publication was not confirmed in the web search. MEDIUM confidence reflects partial verification.]

The ChaoEtAl2020SInter branch (weight 0.10000) is the subduction interface variant of the Chao et al. (2020) Taiwan GMM [DOI:10.1177/8755293019891711], calibrated from the Taiwan flat-file for interface earthquake records. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, $V_{S30,measured}$, $Z_{1.0}$, magnitude, and $Z_{TOR}$ [KB:gmmLT_SIF.md].^[Confidence: HIGH, Rationale: DOI confirmed. Taiwan calibration origin confirmed. Hazardlib parameters from [KB:gmmLT_SIF.md].]

The KuehnEtAl2020SInter branch (weight 0.10000) is the interface variant of the partially nonergodic NGA-Subduction GMM by Kuehn, Bozorgnia, Campbell, and Gregor (2020), developed as part of the PEER NGA-SUB project and providing region-specific adjustments for multiple subduction zones [WEB:https://peer.berkeley.edu/publications/2020-25]. The model is calibrated for global interface conditions. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, magnitude, and $Z_{TOR}$ [KB:gmmLT_SIF.md].^[Confidence: MEDIUM, Rationale: The NGA-SUB context and PEER report are confirmed by web search. A formal Earthquake Spectra journal DOI for the Kuehn et al. (2020) interface model was not confirmed; MEDIUM confidence reflects this gap. Hazardlib parameters from [KB:gmmLT_SIF.md].]

The MontalvaEtAl2017SInter branch (weight 0.10000) is the subduction interface variant of the Chilean GMM by Montalva et al. (2017), calibrated from 3774 recordings spanning 1985-2015 including major megathrust events, over $R_{rup}$ from 20 to 650 km, and published in the Bulletin of the Seismological Society of America [DOI:10.1785/0120160221]. The model is calibrated for the Chilean subduction interface regime. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, a backarc indicator flag, and magnitude [KB:gmmLT_SIF.md].^[Confidence: HIGH, Rationale: DOI confirmed. Calibration dataset (3774 recordings, 1985-2015, Rrup 20-650 km) and backarc parameterization confirmed by web search. Hazardlib parameters from [KB:gmmLT_SIF.md].]

The ParkerEtAl2020SInter branch (weight 0.10000) is the interface variant of the NGA-Subduction global GMM by Parker, Stewart, Boore, Atkinson, and Hassani (2020), providing predictions for peak ground acceleration, peak ground velocity, and 5%-damped pseudo-spectral acceleration at 26 oscillator periods from 0.01 to 10 s, with regional adjustment factors for multiple subduction zones [DOI:10.1177/87552930211034889]. The model is calibrated for global interface conditions. The hazardlib implementation requires $R_{rup}$ and $V_{S30}$ [KB:gmmLT_SIF.md].^[Confidence: HIGH, Rationale: DOI confirmed by web search. The description of IM coverage (PGA, PGV, 26 PSA periods) and regional adjustment structure are confirmed. Hazardlib parameters from [KB:gmmLT_SIF.md].]

The PhungEtAl2020SInter branch (weight 0.10000) is the subduction interface variant of the Phung et al. (2020) model, calibrated from the Taiwan subduction database. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, $Z_{1.0}$, magnitude, and $Z_{TOR}$ [KB:gmmLT_SIF.md]. An external publication DOI was not confirmed during the research phase.^[Confidence: MEDIUM, Rationale: Taiwan calibration context is consistent with search results for Phung et al. (2020). A journal DOI was not confirmed. Hazardlib parameters from [KB:gmmLT_SIF.md].]

The SiEtAl2020SInter branch (weight 0.10000) is a subduction interface GMM by Si and colleagues (2020), calibrated from the Japanese strong-motion database. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, $Z_{2.5}$, hypocentral depth, and magnitude [KB:gmmLT_SIF.md].^[Confidence: MEDIUM, Rationale: The Japanese calibration context is inferred from the hazardlib source file (si_2020.py) and is consistent with the domain literature on Japanese subduction models. A confirmed journal DOI was not found in the web search. MEDIUM confidence reflects this partial verification. Hazardlib parameters from [KB:gmmLT_SIF.md].]
