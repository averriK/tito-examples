## SLOT 5: Stable Continental Crust (SCC) - GMPEs and logic tree

The logic tree for Stable Continental Crust carries the identifier `seed_SCC_modern` and is organised as a single branching level (`bl_SCC`, branch set `bs_SCC`). It comprises six branches with a quasi-uniform weighting scheme: five branches each carry a weight of $0.16667$ and the sixth (`CollapsedNGAEastUSGS`) carries the complementary residual weight of $0.16665$, ensuring the total sums to $1.00000$. The SCC tree is the only one among the four tectonic region types in this assessment that does not achieve exact uniform weighting, owing to the rounding required by the six-branch structure. The KB does not document explicit per-model selection rationale.^[Confidence: HIGH, Rationale: All structural details and weights confirmed directly from [KB:gmmLT_SCC.md]. The quasi-uniform observation (five branches at 0.16667 and one at 0.16665) is a direct reading of the KB data.]

Atkinson (2008), implemented as `Atkinson2008prime`, is a referenced empirical GMPE for stable continental crust conditions in eastern North America (ENA), applying a methodology that adjusts a reference (California-based) GMPE to the ENA attenuation environment using residual analysis and regional scaling. The implementation requires $R_{JB}$ and $V_{S30}$ as site and distance inputs, along with magnitude and rake as rupture parameters. The assigned weight is $0.16667$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SCC.md]. The Atkinson (2008) referenced empirical approach for ENA is well known; the `Atkinson2008prime` designation indicates a modified version. Detailed calibration ranges are not available from KB or external search with sufficient precision.]

Atkinson and Boore (2006), modified 2011, implemented as `AtkinsonBoore2006Modified2011`, is a stochastic-based GMPE for stable continental crust in eastern North America, originally published in 2006 and subsequently revised in 2011 to incorporate magnitude-dependent stress-drop scaling that improved agreement with newer observational data. The model is applicable to the ENA/CEUS region. The OpenQuake implementation requires $R_{\text{rup}}$ as distance metric and $V_{S30}$ as site parameter, along with magnitude as the rupture parameter. The assigned weight is $0.16667$.^[Confidence: HIGH, Rationale: Weight and parameter requirements from [KB:gmmLT_SCC.md]. The AB2006 and 2011 modification are documented in the literature [DOI:10.1785/0120050245]; the model's ENA calibration regime is well established.]

Pezeshk et al. (2011), implemented as `PezeshkEtAl2011`, is a hybrid empirical GMPE for eastern North America that combines NGA-West2 model forms with updated seismological parameters appropriate for stable continental crust. The model spans a magnitude range from approximately $M_w\ 4.0$ to $8.0$ and applies to rupture distances up to approximately $1{,}000$ km, reflecting the long-range attenuation characteristics of stable continental crust. The implementation requires only $R_{\text{rup}}$ and magnitude. The assigned weight is $0.16667$.^[Confidence: HIGH, Rationale: Weight and parameter requirements from [KB:gmmLT_SCC.md]. Magnitude range, distance range, and hybrid empirical methodology are documented in [DOI:10.1785/0120090144].]

The ESHM20 Craton model, implemented as `ESHM20Craton`, is a GMPE developed specifically for cratonic stable continental crust within the 2020 European Seismic Hazard Model, designed to capture the high-frequency-rich attenuation characteristics of old, cold lithospheric shields such as the East European Craton. The implementation requires $R_{\text{rup}}$, $V_{S30}$, and magnitude. The assigned weight is $0.16667$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SCC.md]. ESHM20 craton model characteristics are described in ESHM20 documentation [WEB:https://nhess.copernicus.org/articles/24/1795/2024/]; specific calibration magnitude and distance bounds are not fully specified in available external sources for this GSIM variant.]

Somerville et al. (2009), implemented as `SomervilleEtAl2009YilgarnCraton_SS14`, is a ground-motion model calibrated for rock sites in the Australian Yilgarn Craton, derived from stochastic simulations constrained by local seismological parameters. The model was developed for source magnitudes in the range $M_w\ 5.0$ to $7.5$ and uses Joyner-Boore distance. A modification denoted SS14 is applied. The implementation requires $R_{JB}$, $V_{S30}$, and magnitude. The assigned weight is $0.16667$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_SCC.md]. Magnitude range and the Yilgarn Craton calibration context are described in [WEB:https://www.aees.org.au/wp-content/uploads/2013/11/Somerville-et-al.pdf]; the SS14 suffix designation could not be fully explained from available external sources.]

The Collapsed NGA-East USGS model, implemented as `CollapsedNGAEastUSGS`, is a custom GSIM registered via the local `gmm.gmpe` module that extends the `NGAEastUSGSGMPE` class. It uses a pre-computed HDF5 table (`NGAEastUSGS_collapsed.hdf5`) to represent a collapsed form of the NGA-East USGS ground-motion characterisation model for central and eastern North America, which was developed as a suite of 17 GMPEs covering the stable continental crust regime for magnitudes $M_w\ 4.0$ to $8.2$ and distances up to $1{,}500$ km. The collapsed implementation inflates total sigma with a stored between-model term to preserve the epistemic spread of the original multi-model suite within a single GSIM object. The implementation requires only $V_{S30}$ and magnitude. The assigned weight is $0.16665$.^[Confidence: MEDIUM, Rationale: Implementation details (custom GSIM, HDF5 table, between-model sigma inflation) are taken from [KB:gmmLT_SCC.md]. NGA-East calibration details (magnitude and distance ranges, 17 GMPEs) are from external sources [WEB:https://peer.berkeley.edu/publications/2018-08]. The custom nature of the GSIM and its collapsed representation are specific to this project.]
