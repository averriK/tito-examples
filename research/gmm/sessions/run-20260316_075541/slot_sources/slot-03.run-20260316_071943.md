## SLOT 3: Epistemic uncertainty and ground-motion logic trees

Epistemic uncertainty in PSHA refers to uncertainty arising from incomplete knowledge that is, in principle, reducible with additional data or modelling effort. In ground-motion modelling, this manifests as the inability to identify a single GMM as definitively correct for a given tectonic setting when the observational record is limited. A ground-motion logic tree provides a structured probabilistic representation of this uncertainty by enumerating a set of mutually exclusive and collectively exhaustive model alternatives, each assigned a weight that reflects the analyst's degree of belief in that model given available evidence.^[Confidence: HIGH, Rationale: The distinction between epistemic and aleatory uncertainty and the use of logic trees to represent epistemic uncertainty is established PSHA methodology, consistent with SSHAC guidelines and standard OpenQuake Engine practice [WEB:https://docs.openquake.org/oq-engine/current/manual/].]

In the ground-motion logic trees used in this assessment, each logic tree comprises a single branching level with one branch set applied to a specific tectonic region type. Each branch specifies an alternative GMPE and is assigned a non-negative weight $w_i$ such that

$$\sum_{i=1}^{N} w_i = 1$$

where $N$ is the number of branches. The weights are interpreted as discrete probability masses over the set of candidate models. When all $N$ models are assigned equal weight, $w_i = 1/N$ for all $i$, the logic tree represents a state of maximum model uncertainty, assigning no prior preference to any individual GMPE relative to the others.^[Confidence: HIGH, Rationale: The single-branching-level structure and uniform weighting are confirmed by the KB documents for all four tectonic region types [KB:gmmLT_ASC.md][KB:gmmLT_SCC.md][KB:gmmLT_SIF.md][KB:gmmLT_SIS.md].]

The logic tree is propagated through the PSHA computation by evaluating the hazard integral separately for each branch GMPE and computing a weighted combination of the resulting hazard curves. The mean hazard curve is the weighted average $\bar{\lambda}(y) = \sum_i w_i \, \lambda_i(y)$, where $\lambda_i(y)$ is the mean annual exceedance rate computed with the $i$-th branch GMPE. The full distribution over branches also permits the computation of fractile hazard curves, which characterise the spread of hazard estimates arising from GMM epistemic uncertainty. This framework is the standard mechanism within OpenQuake Engine for capturing model-to-model variability in ground-motion prediction across tectonic region types.^[Confidence: HIGH, Rationale: The weighted-average propagation of logic tree branches through PSHA is standard methodology documented in OpenQuake Engine; the branch structure is confirmed by the KB documents [KB:gmmLT_ASC.md][KB:gmmLT_SIF.md]. No contradictions found.]
