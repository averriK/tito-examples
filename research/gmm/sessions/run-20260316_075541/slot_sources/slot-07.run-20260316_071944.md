## SLOT 7: Subduction Intraslab (SIS) - GMPEs and logic tree

The SIS logic tree bears the identifier `seed_SIS_modern` and is organized under branching level `bl_SIS` and branch set `bs_SIS`. It comprises ten branches, each assigned equal weight $w_k = 0.10000$, with total weight summing to $1.00000$. The uniform weighting follows the same equal-epistemic-standing rationale as the SIF tree. The supporting documentation does not state an explicit model-by-model selection rationale beyond SIS regime applicability. [KB:gmmLT_SIS.md]^[Confidence: HIGH, Rationale: All logic tree identifiers, branch count, uniform weights, and total weight are directly confirmed in the KB document gmmLT_SIS.md.]

The first SIS branch is Abrahamson et al. (2018) for subduction intraslab (`AbrahamsonEtAl2018SSlab`), the slab variant of the BC Hydro NGA-Sub update. The model is calibrated for global subduction intraslab events. In the OpenQuake hazard library it requires $R_{rup}$, $V_{S30}$, and the rupture parameters magnitude and $z_{tor}$. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SIS.md]^[Confidence: HIGH, Rationale: Branch name, weight, and all parameter requirements are directly confirmed by the KB. The intraslab (slab) variant classification of the BC Hydro NGA-Sub model is well established.]

The second branch is Abrahamson and Gulerce (2020) for subduction intraslab (`AbrahamsonGulerce2020SSlab`), the slab variant of the NGA-Sub model. In the OpenQuake hazard library it requires $R_{rup}$, $V_{S30}$, and the rupture parameters magnitude and $z_{tor}$. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SIS.md]^[Confidence: HIGH, Rationale: Branch name, weight, and all parameter requirements are directly confirmed by the KB.]

The third branch is Atkinson (2022) for subduction intraslab (`Atkinson2022SSlab`), the NZ22 slab backbone model. Unlike the interface variant, this implementation requires a backarc flag in addition to $R_{rup}$, $V_{S30}$, and moment magnitude, distinguishing forearc and backarc site attenuation conditions for intraslab events. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SIS.md]^[Confidence: HIGH, Rationale: Branch name, weight, parameter requirements, and the backarc site parameter requirement are directly confirmed by the KB; the backarc flag distinction between the SIS and SIF implementations is evident from comparing the two KB documents.]

The fourth branch is Chao et al. (2020) for subduction intraslab (`ChaoEtAl2020SSlab`), the slab variant of the Taiwan-origin subduction GMPE. In the OpenQuake hazard library it requires $R_{rup}$; the site parameters $V_{S30}$, a $V_{S30}$ measurement flag, and $z_{1.0}$; and the rupture parameters magnitude and $z_{tor}$. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SIS.md]^[Confidence: HIGH, Rationale: Branch name, weight, and all parameter requirements are directly confirmed by the KB.]

The fifth branch is Jaimes and Garcia-Soto (2020) for subduction intraslab (`JaimesEtAl2020SSlab`), an updated GMPE for Mexican intermediate-depth intraslab earthquakes published in Earthquake Spectra. The model was calibrated using 366 records from 23 intraslab events in Mexico, covering $M_w$ approximately 5.0 to 8.2, $R_{rup}$ up to approximately 400 km, and focal depths up to approximately 75 km; the calibration dataset includes recordings from the significant September 2017 intraslab events. In the OpenQuake hazard library it requires both $R_{hypo}$ and $R_{rup}$, as well as $V_{S30}$, hypocentral depth, and moment magnitude. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SIS.md][WEB:https://journals.sagepub.com/doi/10.1177/8755293019899947]^[Confidence: HIGH, Rationale: Branch name, weight, and the combined rhypo and rrup distance requirements are directly confirmed by the KB. The calibration details, including the Mw approximately 5.0-8.2 range, Rrup up to 400 km, depth up to 75 km, and the 2017 event inclusion, are confirmed by the Earthquake Spectra web source.]

The sixth branch is Kuehn et al. (2020) for subduction intraslab (`KuehnEtAl2020SSlab`), the slab variant of the partially non-ergodic NGA-Sub model. In the OpenQuake hazard library it requires $R_{rup}$, $V_{S30}$, and the rupture parameters magnitude and $z_{tor}$. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SIS.md]^[Confidence: HIGH, Rationale: Branch name, weight, and all parameter requirements are directly confirmed by the KB.]

The seventh branch is Montalva et al. (2017) for subduction intraslab (`MontalvaEtAl2017SSlab`), the intraslab variant of the Chilean subduction GMPE. In contrast to the interface variant, which uses $R_{rup}$, this slab implementation uses $R_{hypo}$ as the primary distance metric, consistent with the deeper, more diffuse rupture geometry of intraslab events. The implementation additionally requires the site parameters $V_{S30}$ and a backarc flag, and the rupture parameters hypocentral depth and magnitude. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SIS.md]^[Confidence: HIGH, Rationale: Branch name, weight, and all parameter requirements including the distinction between rhypo (intraslab) and rrup (interface) are directly confirmed by the KB; the difference between SIS and SIF implementations is verified by cross-referencing gmmLT_SIF.md and gmmLT_SIS.md.]

The eighth branch is Parker et al. (2020) for subduction intraslab (`ParkerEtAl2020SSlab`), the slab variant of the global NGA-Sub model. The intraslab component is calibrated for events with $M_w$ in the range 4.0 to 8.4 and $R_{rup}$ from approximately 35 to 2000 km. In the OpenQuake hazard library it requires $R_{rup}$, $V_{S30}$, and the rupture parameters hypocentral depth and magnitude; hypocentral depth is required for the intraslab variant but not for the interface variant. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_SIS.md][WEB:https://peer.berkeley.edu/publications/2020-03]^[Confidence: HIGH, Rationale: Branch name, weight, and parameter requirements (including hypo_depth for the slab variant) are directly confirmed by the KB. The intraslab calibration range Mw 4.0-8.4 and Rrup 35-2000 km are confirmed by the PEER 2020/03 web source.]
