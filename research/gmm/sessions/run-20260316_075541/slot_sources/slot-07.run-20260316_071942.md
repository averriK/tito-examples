## SLOT 7: Subduction Intraslab (SIS) - GMPEs and logic tree

The SIS ground-motion logic tree (logicTreeID: seed_SIS_modern) follows the same structure as the SIF tree: a single branching level (branchingLevelID: bl_SIS), one branch set (branchSetID: bs_SIS) applied to TRT SIS, and ten branches each with weight 0.10000 for a total of 1.00000. The ten branches represent the intraslab variants of global and regional subduction GMMs [KB:gmmLT_SIS.md].^[Confidence: HIGH, Rationale: Tree structure and weights are taken directly from [KB:gmmLT_SIS.md] and are authoritative.]

The AbrahamsonEtAl2018SSlab branch (weight 0.10000) is the intraslab variant of the BC Hydro GMM (Abrahamson, Gregor, and Addo, 2016), calibrated from 2590 recordings of 63 slab events spanning M 5.0-7.9 at distances up to 300 km [DOI:10.1193/051712EQS188MR]. The model is calibrated for global subduction intraslab conditions. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, magnitude, and $Z_{TOR}$ [KB:gmmLT_SIS.md].^[Confidence: HIGH, Rationale: DOI confirmed. Intraslab calibration dataset (2590 recordings, 63 events, M5.0-7.9) confirmed by web search. Hazardlib parameters from [KB:gmmLT_SIS.md].]

The AbrahamsonGulerce2020SSlab branch (weight 0.10000) is the intraslab component of the Abrahamson and Gulerce (2020) NGA-Subduction model, calibrated from 4850 recordings of 89 intraslab events spanning M 5-7.8 from the NGA-SUB database [DOI:10.1177/87552930221114374]. The model is calibrated for global intraslab conditions. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, magnitude, and $Z_{TOR}$ [KB:gmmLT_SIS.md].^[Confidence: HIGH, Rationale: DOI confirmed. Intraslab calibration statistics (4850 recordings, 89 events, M5-7.8) confirmed by web search. Hazardlib parameters from [KB:gmmLT_SIS.md].]

The Atkinson2022SSlab branch (weight 0.10000) is the intraslab backbone model by Atkinson (2022) for the 2022 NZ NSHM, applying the equivalent point-source framework to intraslab earthquake kinematics [WEB:https://pubs.geoscienceworld.org/ssa/bssa/article-abstract/114/1/350/631700/Backbone-Ground-Motion-Models-for-Crustal]. The model is calibrated for the New Zealand intraslab setting. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, a backarc indicator flag, and magnitude; the backarc parameter accounts for systematically reduced ground-motion amplitudes at back-arc sites [KB:gmmLT_SIS.md].^[Confidence: HIGH, Rationale: NZ22 origin and backarc parameterization confirmed by web search and [KB:gmmLT_SIS.md]. The physical motivation for the backarc parameter is a well-established observation in subduction seismology.]

The ChaoEtAl2020SSlab branch (weight 0.10000) is the intraslab variant of the Chao et al. (2020) Taiwan model [DOI:10.1177/8755293019891711], calibrated from Taiwan intraslab records. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, $V_{S30,measured}$, $Z_{1.0}$, magnitude, and $Z_{TOR}$ [KB:gmmLT_SIS.md].^[Confidence: HIGH, Rationale: DOI confirmed. Taiwan calibration origin confirmed. Hazardlib parameters from [KB:gmmLT_SIS.md].]

The JaimesEtAl2020SSlab branch (weight 0.10000) corresponds to the updated GMM for Mexican intermediate-depth intraslab earthquakes by Jaimes and Garcia-Soto (2020), calibrated from 366 records of 23 events extending through the September 2017 Chiapas (M 8.1) normal-faulting event, published in Earthquake Spectra [DOI:10.1177/8755293019899947]. The model is calibrated specifically for the Mexican intraslab setting and provides predictions as a function of magnitude, distance, and focal depth, including vertical-to-horizontal ratios. The hazardlib implementation requires $R_{hypo}$, $R_{rup}$, $V_{S30}$, hypocentral depth, and magnitude [KB:gmmLT_SIS.md].^[Confidence: HIGH, Rationale: DOI confirmed. Calibration dataset (366 records, 23 events, through 2017, including the 2017 M8.1 Chiapas event), V/H ratio coverage, and dual distance metric requirement are all confirmed by web search. Hazardlib parameters from [KB:gmmLT_SIS.md].]

The KuehnEtAl2020SSlab branch (weight 0.10000) is the intraslab variant of the Kuehn et al. (2020) partially nonergodic NGA-Subduction GMM [WEB:https://peer.berkeley.edu/publications/2020-25], calibrated for global intraslab conditions. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, magnitude, and $Z_{TOR}$ [KB:gmmLT_SIS.md].^[Confidence: MEDIUM, Rationale: NGA-SUB context confirmed. Journal DOI not confirmed. Hazardlib parameters from [KB:gmmLT_SIS.md].]

The MontalvaEtAl2017SSlab branch (weight 0.10000) is the intraslab variant of the Montalva et al. (2017) Chilean subduction GMM [DOI:10.1785/0120160221], calibrated for the Chilean intraslab regime. Unlike the interface variant, the intraslab implementation uses $R_{hypo}$ as the distance metric rather than $R_{rup}$, reflecting the different source-geometry conventions applicable to deep slab events, and exhibits steeper distance attenuation than the interface model. The hazardlib implementation requires $R_{hypo}$, $V_{S30}$, a backarc indicator flag, hypocentral depth, and magnitude [KB:gmmLT_SIS.md].^[Confidence: HIGH, Rationale: DOI confirmed. The switch from Rrup (interface) to Rhypo (intraslab) is documented in [KB:gmmLT_SIS.md]. The steeper attenuation finding is confirmed by the web search result summarizing Montalva et al. (2017).]

The ParkerEtAl2020SSlab branch (weight 0.10000) is the intraslab variant of the Parker et al. (2020) NGA-Subduction global GMM [DOI:10.1177/87552930211034889], calibrated for global intraslab conditions. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, hypocentral depth, and magnitude [KB:gmmLT_SIS.md].^[Confidence: HIGH, Rationale: DOI confirmed. Global calibration scope confirmed. Hazardlib parameters from [KB:gmmLT_SIS.md].]

The PhungEtAl2020SSlab branch (weight 0.10000) is the intraslab variant of the Phung et al. (2020) model, calibrated from Taiwan intraslab records. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, $Z_{1.0}$, magnitude, and $Z_{TOR}$ [KB:gmmLT_SIS.md]. An external publication DOI was not confirmed during the research phase.^[Confidence: MEDIUM, Rationale: Taiwan calibration context is consistent with search results. Journal DOI not confirmed. Hazardlib parameters from [KB:gmmLT_SIS.md].]

The SiEtAl2020SSlab branch (weight 0.10000) is the intraslab variant of the Si et al. (2020) GMM, calibrated from Japanese strong-motion data. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, $Z_{2.5}$, hypocentral depth, and magnitude [KB:gmmLT_SIS.md]. The explicit hypocentral depth requirement reflects the well-documented sensitivity of intraslab ground-motion amplitudes to slab depth in Japanese subduction data.^[Confidence: MEDIUM, Rationale: Japanese origin inferred from source file (si_2020.py). The depth sensitivity observation is a well-established finding in Japanese intraslab GMM literature. A confirmed DOI was not found in the web search. MEDIUM confidence reflects partial verification. Hazardlib parameters from [KB:gmmLT_SIS.md].]
