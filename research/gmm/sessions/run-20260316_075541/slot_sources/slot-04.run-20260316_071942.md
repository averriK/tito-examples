## SLOT 4: Active Shallow Crust (ASC) - GMPEs and logic tree

The ASC ground-motion logic tree (logicTreeID: seed_ASC_modern) is organized at a single branching level (branchingLevelID: bl_ASC) containing one branch set (branchSetID: bs_ASC), applied to the tectonic region type ASC. Ten branches are included, each assigned equal weight 0.10000, for a total weight of 1.00000 [KB:gmmLT_ASC.md]. The supporting materials do not provide explicit selection criteria for individual models; the structure reflects a diversity-first approach consistent with the equal-weighting rationale described in the final section.^[Confidence: HIGH, Rationale: The tree structure, identifiers, branch count, and weights are taken directly from [KB:gmmLT_ASC.md] and are authoritative. The absence of explicit per-model selection documentation in the KB is accurately reported.]

The AristeidouEtAl2024 branch (weight 0.10000) corresponds to the artificial neural network-based GMM published by Aristeidou, Shahnazaryan, and O'Reilly (2024) in Soil Dynamics and Earthquake Engineering for traditional and next-generation intensity measures in active shallow crustal settings [DOI:10.1016/j.soildyn.2024.108851]. The hazardlib implementation requires $R_{JB}$, $R_{rup}$, and $R_x$ as distance inputs, $V_{S30}$ and $Z_{2.5}$ as site parameters, and hypocentral depth, magnitude, rake, and $Z_{TOR}$ as rupture parameters [KB:gmmLT_ASC.md].^[Confidence: HIGH, Rationale: The DOI is confirmed by the web search result returning the Soil Dynamics and Earthquake Engineering article. Hazardlib parameter requirements are taken from [KB:gmmLT_ASC.md].]

The Atkinson2022Crust branch (weight 0.10000) is the backbone crustal GMM developed by Atkinson (2022) for the 2022 New Zealand National Seismic Hazard Model (NZ22), employing an equivalent point-source framework calibrated against the New Zealand strong-motion database over approximately M 4-7 and distances up to approximately 400 km [WEB:https://pubs.geoscienceworld.org/ssa/bssa/article-abstract/114/1/350/631700/Backbone-Ground-Motion-Models-for-Crustal]. The model is calibrated specifically for the New Zealand crustal setting. The hazardlib implementation, contained in `nz22/atkinson_2022.py`, requires $R_{rup}$, $V_{S30}$, and magnitude [KB:gmmLT_ASC.md].^[Confidence: HIGH, Rationale: The NZ22 context, calibration range, and backbone framework are confirmed by the web search result referencing the BSSA publication. Hazardlib parameters are from [KB:gmmLT_ASC.md].]

The BooreEtAl2020 branch (weight 0.10000) represents a 2020 GMM by Boore and colleagues for active shallow crustal earthquakes, implemented in the OpenQuake hazardlib in `boore_2020.py`. The hazardlib implementation requires $R_{JB}$, $V_{S30}$, magnitude, and rake [KB:gmmLT_ASC.md]. The KB does not provide a publication reference for this model, and a conclusive external citation was not confirmed during the research phase; this branch is documented on the basis of the KB parameter information only.^[Confidence: MEDIUM, Rationale: The model name and hazardlib parameters are taken from [KB:gmmLT_ASC.md] and are authoritative for the OpenQuake implementation. A specific external publication reference for BooreEtAl2020 as implemented in this module was not confirmed in the web search; MEDIUM confidence reflects this documentation gap.]

The BozorgniaCampbell2016 branch (weight 0.10000) is the NGA-West2 model by Bozorgnia and Campbell (2016), published in Earthquake Spectra [DOI:10.1193/072814eqs121m]. The model is calibrated from the global NGA-West2 database covering active shallow crustal earthquakes over approximately M 3.3-8.5 at distances up to 300 km. The hazardlib implementation requires $R_{JB}$, $R_{rup}$, $R_x$, $V_{S30}$, $Z_{2.5}$, dip, hypocentral depth, magnitude, rake, fault width, and $Z_{TOR}$ [KB:gmmLT_ASC.md].^[Confidence: HIGH, Rationale: The DOI is confirmed by web search results returning the Earthquake Spectra article. The calibration range (M3.3-8.5, up to 300 km) is confirmed. Hazardlib parameters are from [KB:gmmLT_ASC.md].]

The CampbellBozorgnia2019 branch (weight 0.10000) is implemented via the `campbell_bozorgnia_2014.py` hazardlib module and represents the Campbell-Bozorgnia NGA-West2 framework (Campbell and Bozorgnia, 2014) as extended or recalibrated for the 2019 version designation [DOI:10.1193/062913EQS175M]. The base CB14 model was calibrated for active shallow crustal earthquakes over M 3.3-8.5 at distances up to 300 km. The hazardlib implementation requires $R_{JB}$, $R_{rup}$, $R_x$, $V_{S30}$, $Z_{2.5}$, dip, hypocentral depth, magnitude, rake, fault width, and $Z_{TOR}$ [KB:gmmLT_ASC.md].^[Confidence: MEDIUM, Rationale: The DOI cited refers to the CB14 base model; the KB identifies this branch as CampbellBozorgnia2019 but the hazardlib source file is campbell_bozorgnia_2014.py, suggesting the 2019 designation refers to a class extension or recalibration relative to CB14. A distinct 2019 publication DOI was not confirmed. MEDIUM confidence reflects this partial attribution.]

The ChaoEtAl2020Asc branch (weight 0.10000) is the active shallow crustal variant of the horizontal GMM for Taiwan developed by Chao, Chiou, Hsu, and Lin (2020), calibrated from a Taiwan flat-file of more than 40,000 recordings spanning 1992-2016 using a two-step maximum-likelihood regression procedure [DOI:10.1177/8755293019891711]. The model is calibrated specifically for the Taiwan crustal regime. The hazardlib implementation requires $R_{rup}$, $V_{S30}$, $V_{S30,measured}$, $Z_{1.0}$, magnitude, rake, and $Z_{TOR}$ [KB:gmmLT_ASC.md].^[Confidence: HIGH, Rationale: The DOI, calibration dataset (over 40,000 recordings, Taiwan, 1992-2016), and regression methodology are confirmed by the web search result. Hazardlib parameters are from [KB:gmmLT_ASC.md].]

The KothaEtAl2020 branch (weight 0.10000) is the backbone GMM by Kotha and colleagues (2020) serving as the ASC component of the 2020 European Seismic Hazard Model (ESHM20), calibrated from the Engineering Strong Motion (ESM) dataset using recordings primarily from Italy, Turkey, and Greece [WEB:https://nhess.copernicus.org/articles/24/1795/2024/]. The model incorporates a hinge magnitude $M_h = 6.2$ that separates quadratic from linear magnitude scaling. The model is calibrated for the European ASC regime. Uniquely among the ASC logic tree members, the KothaEtAl2020 hazardlib implementation requires only $R_{JB}$, hypocentral depth, and magnitude, with no explicit site parameter [KB:gmmLT_ASC.md].^[Confidence: HIGH, Rationale: The ESHM20 context, ESM dataset, and hinge magnitude Mh=6.2 are confirmed by the NHESS web result. The absence of a Vs30 requirement is taken directly from [KB:gmmLT_ASC.md] and is authoritative for the hazardlib implementation.]

The PhungEtAl2020Asc branch (weight 0.10000) is the active shallow crustal variant of the Phung et al. (2020) GMM, calibrated from the Taiwan strong-motion database. The hazardlib implementation requires $R_{JB}$, $R_{rup}$, $R_x$, $V_{S30}$, $Z_{1.0}$, dip, magnitude, rake, and $Z_{TOR}$ [KB:gmmLT_ASC.md]. An external publication DOI was not confirmed during the research phase.^[Confidence: MEDIUM, Rationale: The Taiwan calibration context for Phung et al. (2020) is consistent with search results referencing this model in the context of Taiwan ground-motion variability. A journal DOI for the ASC-specific publication was not confirmed. Hazardlib parameters are from [KB:gmmLT_ASC.md]. MEDIUM confidence reflects the missing DOI.]

The Stafford2022 branch (weight 0.10000) is the backbone crustal GMM contributed by Stafford (2022) to the 2022 New Zealand NSHM, applying an equivalent point-source framework analogous to the Atkinson (2022) model within the same NZ22 program [WEB:https://pubs.geoscienceworld.org/ssa/bssa/article/114/1/329/631789/The-Ground-Motion-Characterization-Model-for-the]. The model is calibrated for the New Zealand crustal setting. The hazardlib implementation requires $R_{JB}$, $R_{rup}$, $R_x$, $V_{S30}$, $V_{S30,measured}$, $Z_{1.0}$, dip, magnitude, rake, and $Z_{TOR}$ [KB:gmmLT_ASC.md].^[Confidence: HIGH, Rationale: The NZ22 context and Stafford (2022) contribution are confirmed by the web search result referencing the Bradley et al. (2023) BSSA overview of the NZ22 ground-motion characterization model. Hazardlib parameters are from [KB:gmmLT_ASC.md].]

The StewartEtAl2016 branch (weight 0.10000) corresponds to the NGA-West2 equations published by Stewart, Boore, Seyhan, and Atkinson (2016) in Earthquake Spectra for predicting intensity measures from shallow crustal earthquakes, calibrated over approximately M 3-7.9 at distances up to approximately 300 km [DOI:10.1193/072114EQS116M]. The hazardlib implementation requires $R_{JB}$, $V_{S30}$, magnitude, and rake [KB:gmmLT_ASC.md].^[Confidence: HIGH, Rationale: The DOI and authorship are confirmed by web search results returning the Earthquake Spectra article. The calibration scope (NGA-West2, shallow crustal, M3-7.9) is confirmed. Hazardlib parameters are from [KB:gmmLT_ASC.md].]
