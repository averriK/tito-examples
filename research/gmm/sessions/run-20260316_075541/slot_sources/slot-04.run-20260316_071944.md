## SLOT 4: Active Shallow Crust (ASC) - GMPEs and logic tree

The ASC logic tree bears the identifier `seed_ASC_modern` and is organized under branching level `bl_ASC` and branch set `bs_ASC`. It comprises ten branches, each assigned equal weight $w_k = 0.10000$, with the total weight summing to exactly $1.00000$. The uniform weighting reflects the equal epistemic standing afforded to all ten GMPEs in this assessment; the supporting documentation does not provide an explicit model-by-model selection rationale beyond ASC regime applicability. [KB:gmmLT_ASC.md]^[Confidence: HIGH, Rationale: All logic tree identifiers, branch count, uniform weight per branch, and total weight are directly stated in the KB document gmmLT_ASC.md.]

The first branch carries the model of Aristeidou et al. (2024), a GMPE for active shallow crustal earthquakes published in Earthquake Spectra and developed using the NGA-West2 database. The model is calibrated for the ASC regime with records from events of $M_w \geq 4.5$. In the OpenQuake hazard library the implementation requires the distance metrics $R_{jb}$, $R_{rup}$, and $R_x$; the site parameters $V_{S30}$ and $z_{2.5}$; and the rupture parameters hypocentral depth, magnitude, rake, and $z_{tor}$. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale. [KB:gmmLT_ASC.md][WEB:https://gerardjoreilly.github.io/assets/documents/journal-articles/aristeidou-2024-correlations.pdf]^[Confidence: MEDIUM, Rationale: Branch name and weight are confirmed directly by the KB. The second branch is the Atkinson (2022) crustal model (`Atkinson2022Crust`), one of three backbone GMPEs developed for the 2022 New Zealand National Seismic Hazard Model (NZ22) and adjusted to New Zealand-specific magnitude and distance scaling. The model is calibrated for active shallow crust. In the OpenQuake hazard library it requires $R_{rup}$, $V_{S30}$, and moment magnitude. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale beyond ASC classification. The seventh branch is Kotha et al. (2020) (`KothaEtAl2020`), published in the Bulletin of Earthquake Engineering as a regionally adaptable model for active shallow crustal earthquakes in Europe, serving as the backbone GMPE for the 2020 European Seismic Hazard Model (ESHM20). The model was regressed from the Engineering Strong Motion dataset using data from events of $M_w \geq 3$ predominantly from Italy, Turkey, and Greece, via mixed-effects regression that partially resolves spatial variability of attenuation characteristics across active Europe. In the OpenQuake hazard library the current implementation requires $R_{jb}$ and the rupture parameters hypocentral depth and magnitude; no site velocity proxy is required by this implementation. The assigned weight is $0.10000$. The supporting documentation does not state a model-specific selection rationale.
