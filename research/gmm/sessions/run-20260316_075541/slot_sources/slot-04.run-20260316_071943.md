## SLOT 4: Active Shallow Crust (ASC) - GMPEs and logic tree

The logic tree for the Active Shallow Crust tectonic region type carries the identifier `seed_ASC_modern` and is organised as a single branching level (`bl_ASC`, branch set `bs_ASC`) applied globally to all sources classified as ASC. The tree comprises ten branches, each assigned a weight of $0.10000$, so that the total weight sums to $1.00000$ and the ensemble is uniformly distributed over the ten candidate GMPEs. The KB does not document explicit per-model selection rationale; the equal-weight configuration indicates that no discriminating evidence was available to prefer any single model over the others for this region type.^[Confidence: HIGH, Rationale: Logic tree structure, branch IDs, weights, and total weight are taken directly from the KB document [KB:gmmLT_ASC.md]. The absence of selection rationale in the KB is a factual observation about KB content.]

Aristeidou et al. (2024), implemented in OpenQuake hazardlib as `AristeidouEtAl2024`, is a recently developed GMPE calibrated for active shallow crustal conditions using artificial neural network regression on a Mediterranean-focused strong-motion dataset; it is applicable to a magnitude range from approximately $M_w\ 4.5$ and above. The implementation in the OpenQuake hazardlib requires Joyner-Boore distance ($R_{JB}$), closest rupture distance ($R_{\text{rup}}$), and the horizontal distance $R_x$, along with site parameters $V_{S30}$ and $Z_{2.5}$, and rupture parameters including $M$, rake, $Z_{tor}$, and hypocentral depth. The assigned logic tree weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Logic tree weight and distance/site/rupture requirements come from [KB:gmmLT_ASC.md]. The calibration details (neural network, Mediterranean focus, magnitude range) are derived from external search results [WEB:https://gerardjoreilly.github.io/assets/documents/journal-articles/aristeidou-2024-correlations.pdf]; the precise publication venue and magnitude limits for this specific GSIM should be confirmed against the primary paper.]

Atkinson (2022), implemented as `Atkinson2022Crust`, is a backbone GMPE developed for crustal earthquakes in New Zealand as part of the 2022 Aotearoa New Zealand National Seismic Hazard Model (NZ22 model set). It employs equivalent point-source concepts calibrated against New Zealand strong-motion observations and seismological parameters, with applicability spanning approximately $M_w\ 4.0$ to $8.0$ and rupture distances up to approximately $400$ km. The implementation requires $R_{\text{rup}}$ and $V_{S30}$. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and distance metric from [KB:gmmLT_ASC.md]. Publication details and calibration ranges derived from web search results [WEB:https://pubs.geoscienceworld.org/ssa/bssa/article-abstract/114/1/350/631700/]; the GSIM is confirmed as part of the NZ22 model set by its source path in the hazardlib (`nz22/atkinson_2022.py`).]

Boore et al. (2020), implemented as `BooreEtAl2020`, is an update to the NGA-West2 BSSA14 model by Boore, Stewart, Seyhan and Atkinson, extending the prediction equations for shallow crustal earthquakes globally with a revised database and functional form. The model is calibrated for magnitudes from approximately $M_w\ 3.0$ to $8.5$ and Joyner-Boore distances up to approximately $400$ km. It requires $R_{JB}$, $V_{S30}$, and rupture magnitude and rake as predictor variables in the OpenQuake implementation. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and distance requirements from [KB:gmmLT_ASC.md]. Calibration range information derived from the NGA-West2 BSSA14 lineage [WEB:https://peer.berkeley.edu/research/nga-west-2/final-products]; the 2020 revision details should be verified against Boore (2020, BSSA).]

Bozorgnia and Campbell (2016), implemented as `BozorgniaCampbell2016`, provides a vertical-component ground motion model for shallow crustal earthquakes based on the NGA-West2 database. The model spans approximately $M_w\ 3.3$ to $8.5$ and rupture distances up to $300$ km. The OpenQuake implementation requires $R_{JB}$, $R_{\text{rup}}$, and $R_x$ as distance metrics; site parameters $V_{S30}$ and $Z_{2.5}$; and rupture parameters including dip, hypocentral depth, magnitude, rake, width, and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: HIGH, Rationale: Weight and all parameter requirements from [KB:gmmLT_ASC.md]. Calibration regime and range supported by the published NGA-West2 vertical model [DOI:10.1193/072814EQS121M]. Model is well documented in NGA-West2 literature.]

Campbell and Bozorgnia (2019), implemented as `CampbellBozorgnia2019` via the hazardlib module `campbell_bozorgnia_2014.py`, is the CB14 model with subsequent updates, calibrated for active shallow crustal earthquakes using the NGA-West2 database. The model covers approximately $M_w\ 3.0$ to $7.9$ and rupture distances up to $500$ km. The OpenQuake implementation requires $R_{JB}$, $R_{\text{rup}}$, and $R_x$; site parameters $V_{S30}$ and $Z_{2.5}$; and rupture parameters dip, hypocentral depth, magnitude, rake, width, and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_ASC.md]. The CB14 calibration details are documented in [DOI:10.1193/062913EQS175M]; the 2019 designation relative to the 2014 hazardlib implementation filename warrants verification against the primary 2019 publication.]

Chao et al. (2020), implemented as `ChaoEtAl2020Asc`, is a horizontal ground-motion model for crustal earthquakes calibrated primarily on Taiwanese strong-motion records. The model encompasses a broad magnitude range consistent with Taiwan seismicity and is designated for active shallow crustal conditions. The OpenQuake implementation requires $R_{\text{rup}}$; site parameters $V_{S30}$, a measured-$V_{S30}$ flag, and $Z_{1.0}$; and rupture parameters magnitude, rake, and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_ASC.md]. Publication details based on web search [WEB:https://journals.sagepub.com/doi/abs/10.1177/8755293019891711]; specific magnitude bounds from the Taiwan-focused calibration database are not fully specified in available external sources.]

Kotha et al. (2020), implemented as `KothaEtAl2020`, is a regionally adaptable ground-motion model for shallow crustal earthquakes in Europe, developed as a backbone GMPE for the 2020 European Seismic Hazard Model (ESHM20). It is calibrated on a dataset of 23,014 recordings from 2,179 earthquakes predominantly in Italy, Turkey, and Greece, spanning $M_w\ 3.0$ to $7.4$ and Joyner-Boore distances from $0$ to approximately $300$ km. The OpenQuake implementation requires $R_{JB}$ and rupture parameters magnitude and hypocentral depth; no site term is required in the base implementation. The assigned weight is $0.10000$.^[Confidence: HIGH, Rationale: Weight and parameter requirements from [KB:gmmLT_ASC.md]. Calibration details, dataset size, and geographic coverage confirmed by the published ESHM20 backbone GMPE [DOI:10.1007/s10518-020-00869-1]. Strong external citation support.]

Phung et al. (2020), implemented as `PhungEtAl2020Asc`, is a ground-motion prediction equation for crustal earthquakes in Taiwan calibrated using 13,415 ground-motion records from 187 crustal events. The model adopts the Chiou and Youngs (2014) functional form with Taiwan-specific calibration and covers the magnitude range from approximately $M_w\ 3.5$ to $8.0$. The OpenQuake implementation requires $R_{JB}$, $R_{\text{rup}}$, and $R_x$; site parameters $V_{S30}$ and $Z_{1.0}$; and rupture parameters dip, magnitude, rake, and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_ASC.md]. Publication details from web search [WEB:https://journals.sagepub.com/doi/abs/10.1177/87552930211061168]; dataset size of 13,415 records is reported in external search results.]

Stafford (2022), implemented as `Stafford2022`, is a crustal ground-motion model for New Zealand developed as part of the NZ22 model set and derived through adjustments to the Chiou and Youngs (2014) response spectral model based on apparent differences in Fourier spectral parameters. The model is calibrated for $M_w\ 4.5$ to $8.4$ and rupture distances from $0$ to $300$ km. The OpenQuake implementation requires $R_{JB}$, $R_{\text{rup}}$, and $R_x$; site parameters $V_{S30}$, measured-$V_{S30}$ flag, and $Z_{1.0}$; and rupture parameters dip, magnitude, rake, and $Z_{tor}$. The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_ASC.md]; the NZ22 source path in hazardlib (`nz22/stafford_2022.py`) confirms the model identity. Calibration range from web search results [WEB:https://shop.gns.cri.nz/sr_2022-15-pdf/].]

Stewart et al. (2016), implemented as `StewartEtAl2016`, is a GMPE for active shallow crustal earthquakes calibrated for application in Europe and similar tectonic settings, representing a regional adaptation within the NGA-West2 programme. The model requires $R_{JB}$; site parameters $V_{S30}$; and rupture parameters magnitude and rake. Its magnitude and distance applicability ranges follow NGA-West2 conventions ($M_w$ approximately $3.0$ to $8.5$, distances to approximately $300$ km or more). The assigned weight is $0.10000$.^[Confidence: MEDIUM, Rationale: Weight and parameter requirements from [KB:gmmLT_ASC.md]. The publication details and calibration specifics of the StewartEtAl2016 OpenQuake GSIM could not be fully confirmed from available external searches; the NGA-West2 regional adaptation context is inferred from the broader project documentation [WEB:https://peer.berkeley.edu/research/nga-west-2/final-products].]
