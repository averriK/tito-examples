- Bajo `CITATIONS_RULES` + `BIBLATEX_RULES`, generar o refinar un único
  `biblatex.bib` tal que todas las citas `[@Key]` en los chunks tengan entradas
  correspondientes.

En todo momento, considera que:
- La única representación **persistente** de la bibliografía en disco es
  `biblatex.bib`.
- Cualquier estructura auxiliar (tablas de referencias, listas de citas,
  estadísticas) vive dentro de esta sesión y **no** se serializa a archivos
  adicionales en `SESSION_DIR`.

2) Per-chunk cleanup (format-only) and citation normalization

For each chunk entry in `manifest.chunks` (in order):

2.1 Read only this slice
- Construct the absolute path to the slice as
  `/Users/averrik/github/tito-examples/retrieve/WQD/sessions/run-20260112_165029/<chunk.slice_path>` usando exactamente el string de

2.2 Apply format-only cleanup within this chunk
- Apply `FORMAT_RULES` exactly as defined in `rules/format.retrieve.md`:
  - Remove obvious PDF artifacts (headers/footers/page numbers).

  - Do NOT summarize, condense, reorder, or rewrite arguments.
- Keep the language of the source; do not translate.
- Treat fenced/indented code blocks as opaque; do not rewrite or normalize anything inside preformatted/code regions.
- Treat math normalization to LaTeX as the only allowed exception to
  "no rewriting", following the math section of `FORMAT_RULES`.

2.3 Normalize in-text citations to [@Key]
- Within this chunk, detect and normalize citations according to
  `CITATIONS_RULES`:
  - Use the global references table from step 1.

  - Do not normalize or introduce `[@Key]` markers inside fenced/indented code blocks.

- If this slice contains part of the `References` / `Bibliography` section:
  - Use that text only to improve the global references table and
